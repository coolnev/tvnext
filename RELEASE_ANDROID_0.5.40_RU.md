# TVNextR 0.5.40 — Android

Пакет `com.tvnext.app.recovery`, versionCode 540, прежняя подпись. Один release APK: `releases/android/TVNextR-0.5.40.apk`; установка поверх 0.5.39. SHA-256 `a8d838e968d5ea70686ba4a90a1a8ab98b2bbc2b5cbd7e73c17a1985c54baa5b`. Исходники `d1ffb10480fa01f2d17cae4b1243898c4a47de09`.

Реализован согласованный вариант 3 нижней полноэкранной панели: имя канала, одна шкала прогресса со временем, две равные карточки текущей и следующей передач, один ряд управления из трёх групп. Названия не сдвигают кнопки; фокус не меняет их размеры. В обычной панели нет сюжета и кнопки «Описание». Отдельное описание открывается двойным нажатием вправо; автоматическое описание в списке каналов сохранено.

Навигация пультом проходит по доступным кнопкам слева направо, пропуская недоступную перемотку. OK/Enter выполняет действие один раз; удержание перемотки повторяет шаг. Пауза сохраняет фокус, возврат из архива в эфир переводит его на доступное управление. Вверх и Назад закрывают обычную панель.

У адаптивного значка Google TV светлая подложка заменена на сплошную тёмную, добавлен roundIcon. Прямоугольный баннер Android TV, логотип и все прежние PNG значков сохранены побайтно. Проверены контрольные суммы семи исходных изображений и совпадение всех 25 PNG внутри предыдущего и нового APK. Круглая маска показана в `releases/android/validation-0.5.40/google-tv-circle-and-unchanged-tv-banner.png`.

Проверки: 94 channels/UI + 48 native Android API28/35 = 142 без ошибок. Панель проверена на ширинах 720, 1280, 1920; полный снимок Compose — 1920×1080. Пройдены encoding, release, lintVitalRelease, подпись v2, ZIP, zipalign, сохранение встроенного ключа Кинопоиска без публикации в исходниках.

Физический Google TV, реальный поток и запуск этого APK в эмуляторе не проверялись. Снимки панели получены из настоящего Compose-интерфейса с тестовым воспроизведением; круглый значок — визуализация ресурсов и маски.
