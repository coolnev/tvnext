# TVNext 1.0.24 — Windows portable r3

[Скачать один ZIP с GitHub](https://github.com/coolnev/tvnext/releases/download/windows-v1.0.24-r3/TVNext-1.0.24-windows-x64-portable-r3.zip). Распакуйте весь архив и запустите **TVNext.exe**. При обновлении сохраните свою папку `data`. Java и кодеки входят в архив. Версия приложения остаётся **1.0.24**; r3 — обозначение архива. Android-код и APK не изменены.

Раздел настроек показывает все свои параметры сразу. Колонка разделов шире, длинные названия не обрезаются. Постер или кадр в описании имеет ограниченный размер слева, текст расположен справа; описание прокручивается целиком.

Верхнее меню показывает записи, редактор каналов и профили рядом с остальными пунктами, когда хватает ширины. Меню «•••» появляется только для не поместившихся пунктов. При просмотре видео во весь экран подведите мышь к левому краю: поверх видео появится список каналов. Движение мыши обратно к видео закрывает список; есть и кнопка закрытия.

Один щелчок по прямому эфиру показывает управление без паузы. Пробел и отдельная кнопка паузы остаются явными действиями. В архиве и фильмах щелчок переключает паузу; двойной щелчок переключает полный экран. Громкость — компактная тонкая полоса с процентами, доступная также колёсиком над видео.

У архива появилась полоса перемотки мышью и кнопка **«В эфир»**. Для передачи, которая ещё идёт, отмечен текущий эфир, а выбор времени ограничен уже вышедшей частью. Полоса фильма использует относительное время файла, архив — реальное время вещания. Нажатие на канал включает его прямой эфир. Выбранная для просмотра описания передача не становится архивом другого канала. Повторное открытие списка возвращает его к воспроизводимой передаче, а её строка выравнивается напротив канала при разной высоте строк.

Проверены 14 Desktop-тестов, включая настоящее дерево интерфейса с Koin: настройки без сворачивания, адаптивное меню, мышь у левого края, щелчок по эфиру без паузы, выбор времени архива, отметка эфира, кнопка возврата, прямое переключение с архива на другой канал, повторное открытие списка и выравнивание строк. Проверены также границы изображения/текста, ввод с клавиатуры, регулировка громкости, компактные кнопки и сохранение страницы фильма при F11.

Плеер, Windows DLL и движок EPG сохранены из проверенного r2. Побайтовое сравнение JAR плеера и EPG в конечном ZIP подтверждает это; сведения о проверках WASAPI/AAC/AC3 и постоянного gzip-индекса находятся в `releases/windows/validation-1.0.24-r2.json`. Новые UI-проверки выполнены на Linux/Xvfb; физический Windows-ПК и его HDMI/GPU в этой среде недоступны.

Исходники находятся в `main` и теге `windows-v1.0.24-r3`. Сводка проверок и SHA-256: `releases/windows/validation-1.0.24-r3.json`. Предыдущие выпуски Windows и Android сохранены.
