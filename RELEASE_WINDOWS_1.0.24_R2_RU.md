# TVNext 1.0.24 — Windows portable, исправление r2

В первой Windows-сборке отсутствовал звук, не читались сжатые источники EPG, а управление повторяло телевизионное. В r2 исправлены обе ошибки и добавлен отдельный интерфейс Windows. Версия приложения остаётся **1.0.24**. Android-код, общие модули и Android APK не изменены.

[Скачать Windows ZIP с GitHub](https://github.com/coolnev/tvnext/releases/download/windows-v1.0.24-r2/TVNext-1.0.24-windows-x64-portable-r2.zip). Распакуйте весь архив и запустите **TVNext.exe**. Java и кодеки включены. При обновлении сохраните свою папку `data`.

На всех экранах есть навигация: Главная, Каналы, ТВ-гид, Медиатека, Поиск, Настройки. В полноэкранном просмотре она появляется при движении мыши. Кнопки под видео имеют одинаковый размер, центрированные значки и подсказки; доступны громкость, отключение звука, перемотка, предыдущий канал, запись, соотношение сторон и сведения о потоке. Управление помещается и в широком низком окне; фильм сохраняется при пересоздании окна по F11. В списках работают мышь, колёсико, стрелки и Enter.

Один щелчок по видео — пауза, двойной — полный экран; колёсико над видео меняет громкость. Пробел/K — пауза, M — звук, J/L и стрелки над видео — перемотка, Ctrl+стрелки — минута, F11/Alt+Enter — полный экран, Esc — назад, Alt+Home — главная, PageUp/PageDown — каналы. Горячие клавиши не перехватывают ввод в текстовые поля. Полные клавиши описаны в README_RU.txt внутри ZIP.

Причина тишины подтверждена на поставленной Windows DLL: опция `ao=auto` выбирала несуществующий аудиодрайвер, mpv отключал звук. Теперь автоматический выбор устройства использует штатный путь mpv без этой опции; отслеживается реальный аудиовыход и ошибки устройства. Причина отсутствия EPG — чтение сжатых байтов как UTF-8: Windows-адаптер теперь определяет gzip по сигнатуре и распаковывает поток, включая временные файлы `.ready` без расширения `.gz`.

Проверено: 328 JVM/UI тестов (235 IPTV, 85 плеера, 8 Desktop). UI-тесты используют настоящее дерево DesktopShell с Koin и проверяют мышь, пробел, ввод текста, меню, стрелки за пределами видимой области, контраст, центровку и F11 с пересозданием окна. Исходный тест gzip до исправления воспроизводил сбой.

На Windows JRE и DLL из архива через Wine 10 проверены воспроизведение AVC/HEVC, четыре переключения, FPS, пауза, перемотка и освобождение плеера. Аудиовыход WASAPI проверен через захват PCM из виртуального устройства: AAC и AC3 дают ненулевой сигнал, mute — нулевой, громкость снижает уровень. Отдельно Windows-JRE/Ktor/SQLite загрузили gzip EPG и открыли его после перезапуска процесса без второго HTTP-запроса. Полное окно Wine ограничено окружением системных шрифтов; UI проверен на Linux/Xvfb. Проверки физического Windows-ПК, его GPU и HDMI не было.

Контрольная сумма и подробности: `releases/windows/validation-1.0.24-r2.json`, `releases/windows/validation-r2/`. Старый релиз `windows-v1.0.24` сохранён; исправленный — `windows-v1.0.24-r2`.
