## Автофреймрейт

**Настройки → Воспроизведение → Автофреймрейт**. По умолчанию выключен. Доступны включение, плавный режим/смена режима экрана, отдельный подбор разрешения, удвоение низкой частоты, только полный экран и задержка 0.5/1/2/3 секунды. Список поддерживаемых режимов доступен и при выключенной функции, берётся из Android и прокручивается пультом. Показываются текущий режим экрана и известный FPS видео. RU/EN/中文.

Поддерживаются дробные частоты 23.976/29.97/59.94; выбираются кратные им частоты экрана, без округления в соседнее семейство. Уже подходящий режим сохраняется. При отключённом подборе разрешения остаётся исходная геометрия. При включённом выбирается близкий поддерживаемый размер без принудительного снижения ниже видео, если есть больший режим. Смена разрешения разрешена только режиму с переключением экрана.

Запросы меняют только параметры окна TVNext. При выходе из просмотра, завершении/ошибке, фоне, выключении функции и уничтожении Activity возвращаются прежние предпочтения окна. Пауза и краткая буферизация не переключают режим туда-обратно. Старый отложенный запрос отменяется при смене канала. Отказ устройства завершает ожидание через5с и не вызывает бесконечные повторы. Пересоздание Activity из-за размера/плотности экрана предотвращено; старый механизм восстановления Media3 после системных настроек сохранён.

FPS берётся из Media3 Format, при отсутствии — из устойчивых PTS кадров, с ограниченной выборкой и без перерисовки UI на каждый кадр. Media3 Surface frame-rate hints выключены, чтобы они не спорили с AFR окна и переключателем «Выкл». Поддержаны Android API24+, фактическая доступность режимов определяется прошивкой. Подробности и официальные источники: [ANDROID_AUTO_FRAME_RATE_RU.md](docs/ANDROID_AUTO_FRAME_RATE_RU.md).

## Нижняя панель

Перед фактами потока добавлен квадратный **А/П** по фактическому декодеру. Далее **разрешение → кадры/с → звук → аудиокодек**. Например: **А · 1080p · 25 кадр/с · 5.1 · двойная D / AC3**. FPS — частота кадров видео, не герцы экрана. Dolby Digital Plus показан двойной D со знаком «+», TrueHD — с подписью. Эти значки идентифицируют выбранную дорожку, не обещают passthrough/Atmos. Неизвестные значения пропускаются. Одинаково для обычных, компактных и полноэкранных панелей.
