# TVNext 1.0.25 r2 — Windows portable x64

Версия приложения остаётся **1.0.25**; r2 обозначает новую Windows-сборку. Android APK и исходники Android/commonMain не менялись.

В «Воспроизведении» добавлены четыре режима:

- **Авто** — аппаратное декодирование и GPU-вывод при поддержке драйвером, автоматический переход на совместимый вывод при недоступном GPU.
- **Аппаратный — GPU** — D3D11VA и libmpv OpenGL render API через ANGLE/Direct3D 11. Кадры остаются в графической памяти; поверх видео рисуются обычные Compose-панели и анимация.
- **Аппаратный — совместимый** — прежний путь: аппаратное декодирование с копированием кадров в память процессора и выводом через Compose.
- **Программный** — декодирование процессором и совместимый вывод.

Выбор хранится отдельно от Android. Неподдерживаемый видеокодек может декодироваться программно; окно I отдельно сообщает фактический декодер и реальный вывод. Ошибка GPU не маскируется надписью об аппаратном выводе. Системный программный графический драйвер (WARP/Basic Render/llvmpipe) не выдаётся за аппаратный GPU.

MX Player HW+ означает собственный механизм воспроизведения с аппаратным декодером, а не смесь программного и аппаратного декодирования. Поэтому старый Windows-путь назван «совместимым», а не HW+.

F11 и двойной щелчок меняют размер одного окна, сохраняя нативный графический контекст. В оконном режиме есть строка заголовка, перетаскивание, сворачивание, разворачивание и закрытие. Изменение размера сохраняет обычные элементы Compose для недекорированного окна.

Под названием текущей передачи каждого канала есть тонкая полоса прогресса — и в обычном списке, и в списке поверх полноэкранного видео. Подпись «Эфир» находится прямо у красной отметки на шкале, а не в конце строки. Уменьшенные круглые ползунки перемотки и громкости центрированы по вертикали полосы; убраны стандартные дополнительные точки Material.

Проверки и ограничения:

- 20 Desktop Compose/JVM-проверок и 88 проверок core/player. Проверяются выравнивание ползунков на обоих концах/посередине, положение подписи эфира, прогресс каналов в обоих списках, выбор режимов, прежняя навигация мышью/клавиатурой, архив, избранное и настройки.
- Нативные проверки используют Windows JRE и Windows libmpv под Wine 10. Отдельный ANGLE-тест получает реальные кадры через libmpv GPU render API, включая пересоздание render context с восстановлением видеодорожки. Контроллер проверяется с отсутствующим GPU-хостом: автоматический и повторный переход на совместимый вывод, продолжение видео и освобождение ресурсов.
- Полный путь Skia GPU-композиции и аппаратное декодирование на физическом Windows-ПК здесь проверить невозможно. Виртуальный графический драйвер не поддерживает необходимую Skia GPU-поверхность. Это ограничение среды проверки; автоматический совместимый путь проверен отдельно. Не считать Wine проверкой реального Windows GPU/HDMI.
- Содержимое ZIP, SHA-256 и нативные DLL проверяются; приложение включает ANGLE и его лицензию. Android APK сверяется с прежним SHA-256.

[Скачать Windows portable r2](https://github.com/coolnev/tvnext/releases/download/windows-v1.0.25-r2/TVNext-1.0.25-windows-x64-portable-r2.zip). Распакуйте весь ZIP и перенесите свою папку `data` из прежней сборки. Предыдущие релизы сохранены.
