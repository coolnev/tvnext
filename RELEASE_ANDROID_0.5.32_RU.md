# TVNextR 0.5.32 — описание передач и возврат к воспроизведению

Из строк передач полноэкранного списка убрана повторная дата: справа остаётся прежняя колонка дат. В строке сохранены время и название. Оконный список, в котором отдельной колонки дат нет, сохраняет дату для различения суток архива.

Описание из EPG по-прежнему имеет приоритет, если это настоящий текст. Заглушки вроде «Описание передачи отсутствует» больше не перекрывают найденный сюжет. Правило применяется и в списке, и в подробной карточке.

- Кинопоиск и TMDB работают параллельно: медленный TMDB больше не задерживает резервный поиск. Полезное описание публикуется сразу, без ожидания полной карточки и изображений. Общий запрос одного названия и частичный кэш сохраняются.
- Из поискового названия убираются тип передачи, кавычки, возраст и явно оформленный год; номер второй части сохраняется. «Х/ф «Холоп2» (2024) 16+» ищется как «Холоп 2». Первый фильм не считается совпадением второй части.
- Ответ Кинопоиска проверяется по основному, альтернативному и дополнительным названиям. Год помогает выбрать среди совпадений; описание и id полной карточки берутся из одного результата. Лимит поиска увеличен до 20 результатов.
- Ошибка полной карточки или её заглушка не стирает сюжет, полученный из поиска. Настоящее краткое описание используется, если полное поле содержит заглушку.
- При закрытии экрана каналов сбрасывается незапущенный предпросмотр. Повторное открытие полноэкранного списка возвращает фокус к реально воспроизводимому каналу и текущей передаче. Для архива используется время воспроизводимого архива, а не последнее просмотренное место списка.

Проверки: 26 TMDB/Kinopoisk тестов, 55 channels/UI тестов и 22 Android native проверки API 28/35. В Compose проверены отсутствие повторной даты при сохранённой колонке, замена заглушки описанием «Холоп 2», навигация по архиву и работа пульта. Проверены задержанный TMDB, задержанные картинки, правильная часть фильма, альтернативные названия, сохранение частичного ответа и возврат из предпросмотра без смены воспроизведения. Сборка release/lintVital, кодировка, подпись и zipalign проходят.

Ограничение проверки метаданных: среда не разрешает обращения к живым api.poiskkino.dev и api.themoviedb.org. Проверки используют контролируемые ответы API, включая ошибки и задержки; доступность сервиса с ключом и сетью телевизора не подтверждена. Ключи и их настройки сохранены; ключ Kinopoisk.dev по-прежнему должен быть указан в приложении.

APK: `releases/android/TVNextR-0.5.32.apk`. Пакет `com.tvnext.app.recovery`, версия `0.5.32-recovery-preview`, versionCode 532. Прежняя подпись сохранена, сброс данных при обновлении не нужен. Исходники и проверки сохранены на GitHub.

В Android 9 эмулятор установлен именно release APK 532 поверх прежнего приложения. На синтетическом кэшированном EPG подтверждены отдельная колонка дат без повтора в строках и возврат к текущей передаче воспроизводимого канала после незапущенного предпросмотра другого канала/старой передачи. Скриншоты и XML интерфейса сохранены рядом со сводкой. Эмулятор работает без KVM; System UI во время холодного старта показал ANR и был продолжен, поэтому скорость/плавность физического ТВ не оценивается.
