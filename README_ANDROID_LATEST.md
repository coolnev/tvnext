# Последние изменения Android

Актуальное описание: **ANDROID_REVIEW_13_RU.md**.

Включены все предыдущие Android-исправления каналов, архива, ТВ-гида, настроек и медиатеки, а также изменения по последнему списку из 13 пунктов.

В сетке фильмов теперь используются все четыре стрелки; возврат в категории — кнопкой Back. Это заменяет прежнее назначение стрелки влево.

ZIP содержит полный проект с исходниками. Сборка APK и запуск тестов заблокированы недоступностью скачивания Gradle в рабочей среде; успешная компиляция не подтверждена.

## Дополнительные правки TV Guide / телепрограммы — 7 сентября 2026

- Android TV Guide ограничен ровно пятью видимыми строками каналов; шестая строка не заходит под нижнюю область описания.
- После long press OK при переходе из полноэкранного видео в TV Guide физический KeyUp блокируется межэкранным `OkInputGate`, поэтому продолжительное удержание OK не открывает описание.
- Back внутри Android TV Guide возвращает фокус на верхнюю панель и не закрывает Guide.
- Список передач конкретного канала теперь трактуется как полноценная «Программа передач»: загружается реальный доступный диапазон EPG канала, а не искусственное окно вокруг текущего времени.
- В списке передач добавлены разделители календарных дат; переход через полночь визуально отделяет новый день.
