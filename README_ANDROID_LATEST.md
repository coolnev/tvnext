# TVNext 1.0 — Android

[Скачать TVNext-1.0.apk](releases/android/TVNext-1.0.apk) · [Изменения и проверка](RELEASE_ANDROID_1.0_RU.md)

Основная рабочая ветка с полными исходниками — `main`. Версия Android — **1.0**, versionCode **1000**, пакет **com.tvnext.app**, подпись оригинальной 0.5.21. Общий интерфейс и информация о приложении также показывают 1.0; настройка версии пакета Desktop — 1.0.0.

На главной название текущего канала/фильма и видео справа образуют один блок с общей рамкой и одной остановкой фокуса пульта; OK открывает полный экран. Названия под видео и отдельной ленты «Сейчас идёт» нет. Сообщение о выходе показывает только текст.

Оформление → Язык интерфейса: **Русский / English / 中文（简体）**. Переводятся меню и подсказки, исходный контент провайдера сохраняется. Удалены дублирующий акцентный цвет, запуск на весь экран в общих настройках Android и «Мои записи» из обслуживания; записи остаются на главной.

Повторное нажатие записи на записываемом канале останавливает и запись по расписанию. В библиотеке доступны «Остановить» и подтверждение «Остановить и удалить». Удаление ждёт завершения записи; технические recording/partial заменены понятными статусами на выбранном языке.

Этот APK обновляет исходный пакет com.tvnext.app, включая 0.5.21. Версия 0.5.45 com.tvnext.app.recovery — отдельное приложение; Android автоматически не переносит его частные данные. Её установка и данные не удаляются.
