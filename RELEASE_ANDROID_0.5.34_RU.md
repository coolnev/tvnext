# TVNextR 0.5.34 — плотный список передач и ключ Кинопоиска

Количество строк передач удвоено в обоих вариантах полноэкранного гида: с описанием снизу и справа. Пять строк каналов соответствуют десяти строкам передач, девять — восемнадцати. Размер строк каналов сохраняется. Текущая передача располагается в верхней половине строки выбранного канала, примерно напротив него. В строке передачи остаются время и название; описание доступно в панели.

При возврате из списка передач в колонку каналов незапущенный выбор сбрасывается к реальному воспроизведению. Другой канал открывает свою текущую программу, а не время просмотренного курсором архива. Если реально воспроизводится архив, при открытии гида играющего канала сохраняется фокус его архивной передачи.

Предоставленный пользователем ключ Кинопоиска встроен в APK как значение по умолчанию. Он доступен сразу при запуске, включая чистую установку и пустое сохранённое поле; открывать настройки для его ввода не требуется. Другой вручную сохранённый ключ имеет приоритет; пустое поле возвращает встроенное значение. Значение ключа не добавлялось в текст исходников и отчётов GitHub. Для следующих сборок оно задано локальным Gradle property `tvnext.kinopoisk.defaultKey`; поддерживается `TVNEXT_KINOPOISK_DEFAULT_KEY`.

Проверки: 28 metadata, 64 channels/UI и 24 Android native — 116 без ошибок. Четыре новые проверки воспроизводили прежние ошибки и проходят после исправления. Проверены плотность 5/10 и 9/18, геометрическое выравнивание, пульт, возврат из незапущенного архива, смена канала и сохранение фокуса реально воспроизводимого архива. Проверен заголовок API-запроса с ключом по умолчанию, ручным ключом и после повторного создания хранилища. Release, lintVital, кодировка, ZIP, подпись v2 и zipalign проходят.

Release APK установлен поверх 0.5.33 в Android 9 эмуляторе. На его размере экрана видны 7 каналов и 14 передач; в настройках отображается «Ключ задан» при отсутствии сохранённого ключа в тестовой базе. Установленный APK совпадает по SHA-256 с выдаваемым файлом. FATAL/ANR приложения не зафиксированы. Синтетический видеопоток недоступен; физический ТВ и плавность его видео не проверялись. Живой API Кинопоиска блокирует сеть окружения, поэтому доступность сервиса с ключом не подтверждается этой проверкой.

APK: `releases/android/TVNextR-0.5.34.apk`, `0.5.34-recovery-preview`, versionCode 534, пакет `com.tvnext.app.recovery`. Прежняя подпись позволяет обновление с сохранением данных. Исходники: `9c1e0b0`. Сводка: `releases/android/validation-0.5.34.json`, скриншоты и проверки — в каталоге рядом.
