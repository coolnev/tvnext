# TVNext 0.2.7 — описание и управление воспроизведением

- На Android раскрытое описание передачи (второе нажатие вправо) остаётся открытым до явного закрытия. Общий таймер архива больше не закрывает описание вместе с панелью управления.
- На паузе нижняя панель управления остаётся видимой. Это действует и при паузе с пульта/внешнего управления, когда кнопка на экране не нажималась.
- После продолжения просмотра запускается новый полный интервал скрытия из «Оформление → Информация о передаче»; учитываются изменения интервала, дальнейшие действия пользователя и режим постоянного отображения.
- Удалены большие отдельные значки паузы/воспроизведения поверх видео в архиве и Android-медиатеке. Кнопки самой панели управления сохранены.
- Перемотка в медиатеке использует тот же таймер; отдельный короткий таймер больше не скрывает панель раньше выбранного времени.
- Поведение проверено на общем UI под Linux/Xvfb и с виртуальным временем, в том числе: второе нажатие вправо, описание после 15 секунд, закрытие кнопкой Назад, длительная пауза и полный 7-секундный интервал после продолжения. Физический телевизор TCL и запуск Windows в облачной среде недоступны.

## Новая тема — только образец

«Контур»: белые рамки окон, полупрозрачные тёмные поверхности, мягкие тени и мятный акцент. Это предложенный визуальный концепт для согласования, не снимок установленной темы. В 0.2.7 включены исправления плеера; внедрение новой темы будет отдельным изменением после выбора пользователя.

Образец: https://github.com/coolnev/tvnext/raw/refs/heads/artifacts/contour-preview-20261025/TVNext-Contour-concept.png

## Установка

Android: установите `TVNext-0.2.7-release.apk` поверх предыдущей версии. Сборка release, без отладки, с оптимизацией. Сохранён прежний тестовый сертификат подписи для обновления поверх предыдущих сборок.

Windows x64: закройте приложение, распакуйте весь `TVNext-0.2.7-windows-x64-portable.7z` и запустите `TVNext/TVNext.cmd`. Java 21 и библиотеки воспроизведения включены. Настройки сохраняются в `%USERPROFILE%\.tvnext`.
