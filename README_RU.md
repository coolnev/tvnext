# TVNext 0.5.2 для Windows x64

[Скачать portable 0.5.2](https://github.com/coolnev/tvnext/raw/refs/heads/artifacts/windows-0.5.2-20261026/TVNext-0.5.2-windows-x64-portable.7z)

Распакуйте весь архив через 7-Zip и запустите `TVNext.cmd` из папки `TVNext`. Java 21 и mpv включены. Настройки и история сохраняются в `%USERPROFILE%\.tvnext`.

## Изменения

- Исправлена очередь изображений: картинка из памяти отображается сразу, без ожидания сетевых запросов логотипов. Для кадров и постеров в открытом описании выделена отдельная ограниченная очередь загрузки.
- Рабочий постер остаётся видимым, пока загружается изображение TMDB. Если замена не загрузилась, постер сохраняется. Доступное изображение провайдера показывается параллельно загрузке кадра и постера TMDB; успешно загруженный кадр получает приоритет.
- При временной ошибке изображения повторно запрашиваются, пока описание открыто. Закрытие панели или выбор другой передачи отменяет ненужные запросы. Постер предыдущего фильма не переносится в описание следующего.
- Исправления применены к нижним карточкам каналов и фильмов, оконному описанию медиатеки и боковым постерам Windows.
- При остановке HLS-предзагрузки отменяются ожидающие задачи и завершаются активные процессы curl. Отмена больше не выводится как `segment … FAILED: Job was cancelled`. Очищается временный кеш сегментов; неудавшееся скачивание сегмента не считается успешным.
- Сохранены исправления EPG, поиска и управления из Windows 0.5.1.

## Проверка

Проверены 40 последовательных смен наборов изображений с отменой запросов и загрузкой новых кадров при занятых сетевых слотах; показ постера во время загрузки и после ошибки TMDB; повторная загрузка без закрытия описания; реальные панели медиатеки при обновлении позиции плеера. Интеграционные тесты HLS используют локальный HTTP-сервер и настоящие процессы curl: повторные открытия/закрытия, отмену загрузки плейлиста, остановку процессов и удаление временного кеша.

Все 312 тестов прошли; общие изменения также прошли компиляцию для Android. Автоматические проверки и сборка выполнены на Linux. Физический запуск Windows и доступность TMDB на компьютере пользователя здесь не проверены. Android APK в этом выпуске не обновляется; доступна версия 0.5.
