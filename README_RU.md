# TVNext 0.5.13 — Android

## Проверка Kinopoisk.dev

API-ключ вводится целиком, с обычными дефисами, без кавычек и пробелов по краям: «Настройки → Медиатека → Kinopoisk.dev · резерв». Регистр и символы ключа сохраняются. В поле отключена автокоррекция экранной клавиатуры, добавлена подсказка по вводу. Ключ пользователя в сборку не включён.

Вместо поиска десяти полных карточек проверка соединения теперь запрашивает один ID фильма. Она не зависит от необязательных полей карточек и скорости текстового поиска. Срок проверки увеличен с пяти до двенадцати секунд, отдельного HTTP-запроса — до десяти секунд. Эти изменения не отменяют проверку HTTPS и не разрешают пересылать ключ при перенаправлении на другой адрес.

Сообщения различают неверный ключ, отказ доступа, ограничение сервиса, DNS, TLS, тайм-аут, прочую сетевую ошибку, перенаправление и некорректный ответ. Если сервер ответил, показывается HTTP-код. Сетевые ошибки больше не объединяются с ошибкой разбора JSON в одну надпись. Интерфейс переведён на русский, английский и китайский.

## Загрузка карточек

Допускаются null в необязательных списках названий и жанров, а также элементы жанров без названия. Зависший дополнительный запрос подробностей больше не уничтожает уже полученную полезную поисковую карточку. Поиск по-прежнему проверяет название, год и тип произведения. Для загрузки карточки сохраняется общий лимит времени; проверка соединения не ставится в очередь поиска.

## Проверки и установка

610 проверок без ошибок и пропусков. Проверены точная передача ключа, сохранение ключа с дефисами, лёгкий запрос проверки, ответ дольше прежних пяти секунд, допустимые null, сохранение результатов при зависших подробностях, HTTP-ошибки, DNS/TLS/тайм-ауты, отмена запроса, скрытие ключа и перевод сообщений в настройках. Сборка выполнена с Android host-тестами и JVM/Compose-тестами на Linux/Xvfb. Физический телевизор не проверялся.

Из облачной среды api.kinopoisk.dev недоступен: сетевой прокси отклоняет соединение до обращения к сервису. Поэтому действительность пользовательского ключа и работа реального API не подтверждены. Это исправление проверки и обработки ответов, а не подтверждение устранения сетевой проблемы на телевизоре. Если ошибка сохраняется, новая точная надпись позволит определить дальнейшее действие. Ключ повторно присылать не требуется.
