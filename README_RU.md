# TVNext 0.5.3 для Windows x64

Файл portable: `TVNext-0.5.3-windows-x64-portable.7z`.

Закройте TVNext, распакуйте весь архив через 7-Zip и запустите `TVNext.cmd`. Java 21 и mpv включены. Настройки и история сохраняются в `%USERPROFILE%\.tvnext`.

## Изменения

- Изображения: запасной официальный сервер TMDB подключается через 300 мс, не дожидаясь зависшего основного. Время всей загрузки ограничено, включая чтение тела ответа; незавершённые ответы закрываются. Ответ HTTP 200 с заглушкой вместо картинки не мешает получить изображение с другого сервера.
- Медиатека: исправлены HTTP-перенаправления, сжатые HLS-плейлисты, разрешение относительных ссылок после перенаправления, ссылки на ключи AES и файлы инициализации fragmented MP4. Сохраняются расширения сегментов.
- Локальный ускоритель HLS проверяет доступность первого сегмента перед передачей потока плееру. При ошибке приложение использует исходный адрес. Для неподдерживаемых ускорителем схем HLS также сохраняется штатное воспроизведение mpv.
- Заголовки провайдера в адресе потока применяются к запросам Windows и очищаются при переходе на следующий источник.
- Перемотка мышью использует актуальную длительность и обработчик текущего фильма, даже после смены фильма или обновления данных. Исправлены щелчок и перетаскивание шкалы.
- Архив: при отсутствии длительности в потоке шкала использует начало и конец передачи из EPG. Работает в окне и на полном экране.
- В полноэкранном просмотре фильма или архива движение мыши показывает шкалу поверх видео. Панель остаётся при наведении и паузе; после возобновления скрывается через интервал из настроек.

## Клавиатура Windows

- `←` / `→` на видео — перемотка архива или фильма. В списках стрелки продолжают управлять списками.
- `Shift` + стрелка — 5 секунд; `Ctrl` + стрелка — 30 минут.
- `C` — список каналов/фильмов; `D` — описание.
- `Пробел` — пауза/воспроизведение; `Escape` — закрыть панели; `F11` — полный экран.

## Проверка

HLS проверен настоящим FFmpeg через рабочий HTTP-прокси приложения: обычный и зашифрованный HLS, master-плейлист, fragmented MP4, HTTP-перенаправления, gzip и перемотка. Отдельно проверен переход на исходный поток при недоступном первом сегменте. Проверки Compose охватывают стрелки, щелчок и перетаскивание, обновление длительности, архив без длительности потока и таймер панели при паузе.

Все 327 автоматических тестов прошли. Общие изменения прошли компиляцию для Android; проверка кодировки исходников также пройдена. Проверки выполнялись на Linux. Реальный адрес провайдера и внешние серверы TMDB в этой сессии недоступны из-за отсутствия сетевого доступа облачной среды. Физический запуск на Windows не проверен. Android APK в этом выпуске не обновляется.
