# TVNext 0.5.11 — Android

## Соотношение сторон без возврата к предыдущему каналу

- Возврат из настроек сохраняет уже активный канал или архив. Чтение сохранённого канала больше не имеет приоритета над текущим воспроизведением.
- После приостановленного чтения настроек проверяется актуальное воспроизведение и версия запроса. Запоздавшее восстановление не отменяет новый выбор пользователя.
- Даже при временно неполном списке каналов активный поток не заменяется другим каналом из сохранённого состояния.
- Снимок Android-сессии обновляется синхронно при начале нового воспроизведения, включая выбор в фоне.
- Смена пропорций записывает одну настройку, не переписывая остальные параметры и историю выбранного канала.

## Кнопка пропорций в нижней панели

В панели информации, открываемой однократным нажатием вправо, слева по вертикальному центру находится кнопка в виде экрана. На ней указан текущий формат: «Авто», «Экран» либо числовое соотношение сторон. Значение берётся из активного Android-плеера.

Нажмите OK или вниз, чтобы перейти к кнопкам панели. Новая кнопка получает фокус; OK открывает меню вариантов по центру экрана. Список прокручивается к текущему режиму, который сразу получает фокус. При выборе режим применяется и сохраняется, меню закрывается, фокус возвращается на кнопку. Стрелка вправо переводит к кнопкам архива; влево от первой кнопки перемотки возвращает к пропорциям.

Панель не исчезает по таймеру, пока меню открыто. После закрытия меню отсчёт запускается заново по настроенному интервалу. Правила паузы и раскрытого описания сохраняются.

Доступны все режимы 0.5.10, включая «Автоматически», 16:9, 4:3 и киноформаты. Переход в настройки для их изменения больше не обязателен.

## Отметка архива

У каналов с заявленной поддержкой архива часы уменьшены до 12 dp и перенесены внутрь поля названия, в правый верхний угол. Это информационная отметка без действия и без отдельной точки фокуса. Отдельный столбец с кнопкой часов на Android удалён; освободившееся место используется названием и телепрограммой. Для каналов без признаков архива отметка не рисуется.

## Сборка и установка

`TVNext-0.5.11-release.apk`: версия 0.5.11, код 25. Релизная конфигурация с минификацией, без debuggable, с той же тестовой подписью, что и предыдущие APK. Включены arm64-v8a, armeabi-v7a, x86, x86_64. Установите поверх предыдущей версии; удалять приложение и очищать данные не требуется.

Этот выпуск содержит только APK Android. Сборка Windows в рамках этой работы не выпускается.

Пройдены 422 проверки без ошибок и пропусков.

Проверены сценарии восстановления со старым сохранённым каналом и задержанным чтением настроек, независимая запись пропорций, расположение и фокус новой кнопки, выбор текущего режима в меню, управление пультом, возврат между кнопками панели, блокировка автоскрытия на время меню, а также положение и отсутствие действия у отметки архива. Проверки выполняются в Linux/Xvfb с общим обработчиком TV-пульта и Android host-тестами; физический телевизор здесь не проверялся.
