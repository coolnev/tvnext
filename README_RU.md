# TVNext 0.2.3 — переключение оформления

В «Настройки → Темы» доступны «Классическая» и «Крупная для ТВ». Выбор применяется сразу и сохраняется после перезапуска. У существующей установки сохраняется классическое оформление; для нового варианта выберите «Крупная для ТВ». Возврат к классической теме доступен без переустановки и отката версии.

Крупная тема: увеличенные надписи и строки, светлый текст, спокойные тёмные подложки, заметная рамка фокуса и полоса выбора. В полноэкранном списке видны категории, каналы, передачи и даты; на широком экране добавляется описание передачи. Размеры кнопок в строке канала оставляют место его названию.

Исправлен нечитаемый чёрный текст в передачах, датах и описаниях в обеих темах. Цветовой режим и цвет акцента остаются отдельными настройками. Навигация и привязка архивной передачи ко времени воспроизведения сохранены. При переключении темы выбранная дата и фокус не теряются. Активная категория также центрируется при открытии списка.

APK: оптимизированная сборка release 0.2.3 (versionCode 5), минификация и сокращение ресурсов включены, отладка отключена. Используется прежний тестовый сертификат подписи, поэтому предыдущую выданную сборку можно обновить без удаления приложения и настроек.

Windows x64: распакуйте весь архив .7z с помощью 7-Zip или совместимого архиватора и запустите TVNext/TVNext.cmd. Java 21, mpv и Vulkan Loader включены; отдельная установка Java не нужна. Пользовательские данные хранятся в %USERPROFILE%\.tvnext. Используйте отдельную папку для новой сборки.

PNG рядом со сборками — реальные скриншоты общего интерфейса на тестовых каналах под Linux/Xvfb, а не дизайнерские макеты.

Проверка: 39 тестов каналов и интерфейса, 6 тестов настроек, 40 тестов Android-плеера; ошибок нет. Включены проверки цветов, выбора обеих тем, сохранения темы после закрытия и открытия базы, переходов между каналами/передачами/датами и возврата к классическому оформлению во время просмотра архива. Проверены подпись/версия APK, целостность Windows-архива и неизменность данных при перепаковке JAR. На физическом TCL и Windows-компьютере эта сборка в облачной среде не запускалась.

SHA256SUMS содержит контрольные суммы файлов. Ветка загрузок содержит только сборки, скриншоты и этот документ.
