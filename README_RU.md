# TVNext 0.5.15 — Android

## Размер раскрытого описания зависит от текста

Окно, открываемое вторым нажатием вправо, теперь имеет естественную высоту по содержимому. Короткое описание делает окно ниже, длинное — выше. Максимальная высота ограничена 85% доступной области видео, а тексту выделяется оставшееся после заголовков и кнопок место. Управление остаётся видимым. Изображение видео под окном не уменьшается.

Когда текст не помещается по высоте, всё содержимое описания прокручивается с паузами в начале и конце. Текст можно прокручивать касанием. Раскрытое окно сохраняется до закрытия пользователем, как и ранее.

Описание обтекает изображение: начало находится справа от кадра/постера, продолжение — под ним на всю ширину. Для разделения используются реальные метрики шрифта и переноса строк; сохраняются абзацы, китайские символы и emoji. При изменении ширины или размера шрифта перенос рассчитывается заново.

Высота изображения составляет 118 dp, вертикальный постер занимает узкую полосу по своим пропорциям. Пока изображение не загрузилось либо если оно недоступно, текст начинается у левого края; пустого прямоугольника и промежутка нет. При позднем появлении картинки текст перестраивается. Сам загрузчик сохраняет место в композиции и не перезапускает запрос из-за этой перестройки.

Изменение применяется только к раскрытому Android-описанию при просмотре видео, для обоих вариантов размещения описания в настройках. Компактные карточки в списках/ТВ-гиде и опубликованная Windows-версия не менялись. Настройки тем и прозрачности продолжают использоваться.

## EuroLux VIP 4K60FPS

Воспроизведение EuroLux VIP 4K60FPS этим выпуском не исправлено. Источник плейлиста из облачной среды недоступен; точные параметры реального потока и причина аппаратного отказа не установлены. Для дальнейшей проверки нужна точная модель TCL.

Порядок автоматического декодирования из 0.5.14 сохранён: аппаратный → системный программный → FFmpeg, аудио восстанавливается отдельно. Не вводились предположительные настройки кодека по одному названию канала. Разрешения 4K и частоты 60 fps недостаточно для вывода о поддержке: важны кодек, профиль, уровень и возможности чипа. Точную модель можно посмотреть на наклейке телевизора или в разделе «Об устройстве»; для этого не требуется присылать диагностику.

## Проверки и установка

636 проверок без ошибок и пропусков. Добавлены проверки роста/уменьшения окна, перехода текста под кадр, позднего вертикального постера без повторного запроса, отсутствующего изображения, увеличенного шрифта и переноса абзацев/emoji/китайского текста. Второе нажатие вправо проверено с длинным описанием и видимыми кнопками в обоих вариантах размещения. Фактическая отрисовка изображения проверяется пикселями тестового кадра. Проверки выполнены на Linux/Xvfb с Android host-тестами; на физическом телевизоре не проверялось.

TVNext-0.5.15-release.apk: версия 0.5.15, код 29, minSdk 24, targetSdk 36. Release-сборка с минификацией, без debuggable, с прежней тестовой подписью, arm64-v8a, armeabi-v7a, x86, x86_64. Устанавливается поверх предыдущей версии с сохранением настроек и ключей.

Исправление адреса резервного API api.poiskkino.dev и быстрое переключение каналов из 0.5.14 сохранены. Windows не пересобиралась; опубликованная версия остаётся 0.5.10.
