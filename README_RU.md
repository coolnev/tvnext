# TVNext Android 0.5.18 — эфир, запись и продолжение архива

[Скачать release APK](https://github.com/coolnev/tvnext/raw/refs/heads/artifacts/release-0.5.18-20261028/TVNext-0.5.18-release.apk)

При просмотре с начала ещё идущей передачи на полосе прогресса теперь отдельно показаны просмотренная часть, уже доступная часть эфира и ещё не вышедшая часть передачи. Красная отметка «ЭФИР» показывает текущее место прямой трансляции; рядом отображается отставание. На паузе отметка эфира продолжает двигаться. Шкала строится по времени передачи из EPG, а не по длине отдельного архивного фрагмента. После окончания передачи отметка убирается.

На нижней панели прямого эфира появилась кнопка «Записать эфир». Она сохраняет исходное видео и звук без перекодирования. Остановить запись можно той же кнопкой или в разделе «Мои записи» на главном экране. Запись продолжается при переходе между экранами приложения и переключении канала. При уходе приложения в фон запись завершается: фоновой службы и расписания в этом выпуске ещё нет. Провайдер должен разрешать дополнительное подключение к потоку.

Одна запись длится до конца текущей передачи плюс 30 секунд, максимум два часа; без EPG — максимум два часа. Одновременно доступна одна запись. Файлы находятся во внутреннем хранилище приложения. Общий предел — 4 ГБ; при нехватке места запись останавливается, старые файлы автоматически не удаляются. «Мои записи» позволяет смотреть сохранённое видео, перематывать, ставить на паузу, удалять с подтверждением и сохранять ZIP через системный выбор файла. ZIP содержит локальный плейлист и сегменты либо TS-файл, а не MP4. Удаление приложения удалит внутренние записи; нужные файлы следует экспортировать заранее.

Поддерживаются HLS с совместным видео и звуком, AES-128, TS/fMP4-сегменты и байтовые диапазоны, а также прямой MPEG-TS с пакетами 188 байт. HLS с отдельными внешними аудиодорожками, DRM и DASH в этой первой реализации не записываются: показывается ошибка формата. При обрыве сохраняется завершённая часть. После аварийного закрытия она восстанавливается в списке как частичная запись.

Архив автоматически запоминает позицию просмотра отдельно для каждого профиля. На главном экране появляется раздел «Продолжить архив». Хранятся до 20 передач, в том числе несколько передач одного канала. При возобновлении строится новый адрес потока для сохранённого времени; старые адреса с временными токенами в позиции не сохраняются. Передачи за пределами глубины архива скрываются. Завершённая передача убирается из продолжения.

Записи общие для устройства; воспроизведение и экспорт защищённых каналов проходят через существующую проверку родительского PIN. Успешная разблокировка действует до закрытия приложения. Заголовки защищённых передач скрываются до разблокировки.

В Android также усилен выбор декодера: плеер получает только выбранный видеобэкенд. В автоматическом режиме аппаратный путь пробуется первым, системный программный — вторым, FFmpeg — последним. Отдельный резерв для звука не переключает видео на FFmpeg. Явное аппаратное декодирование не заменяется программным.

Release APK: versionCode 32, минификация, отладка отключена, прежняя подпись. Устанавливается поверх 0.5.17 без очистки данных. Асинхронный запуск из исправления 0.5.17 сохранён. RU/EN/中文 поддерживают новые элементы. Платёжная блокировка и таймер сна не добавлялись.

Все 693 автоматические проверки прошли без ошибок и пропусков, включая сохранённые проверки запуска на пустой базе и после миграции, запись HLS/TS, AES-128, ограничение места, отмену, восстановление после прерывания, изоляцию архивных позиций и движение отметки эфира на паузе.

Именно финальный минифицированный release APK проверен на Android 10 / API 29 x86_64 в эмуляторе: обновление с 0.5.17, чистый запуск, открытие настроек, запись HLS со звуком, продолжение архива после перезапуска процесса, просмотр записи, перемотка и пауза. Экспорт через системный выбор файла дал ZIP с 64 файлами; независимая проверка подтвердила H.264 + AAC и длительность 126 секунд, видео и звук успешно декодированы. В финальном проходе ошибок запуска и нативных падений в журнале приложения не было.

Первый графический режим эмулятора давал нативные сбои и искажённые кадры, в том числе на прежней 0.5.17. Финальная проверка выполнена после смены графического режима и с системным программным видеодекодером в AUTO. Работа FFmpeg-видео и аппаратное декодирование на физическом TCL требуют отдельной проверки.

Windows не пересобиралась и остаётся на 0.5.10. Физический телевизор TCL и проблемный EuroLux VIP 4K60FPS этим выпуском не проверены.
