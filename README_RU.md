# TVNext 0.2.10 — компоновка «Контура» и постеры

Android TV и Windows x64.

- Списки «Контура» располагаются поверх полноэкранного видео. Переключение между нижним и правым описанием не уменьшает область плеера.
- Во время просмотра списков скрывается фоновая надпись с названием архивной передачи, чтобы она не просвечивала через категории.
- Описание справа доступно и на экране шириной 960 dp: прежний порог 1180 dp больше не скрывает его. Панель программ использует всю оставшуюся ширину, без незанятой полосы видео справа.
- Категории «Контура» сужены с 240 до 156 dp; каналам сохранено 300 dp. Освободившаяся ширина передана программам. При нижнем описании списки заканчиваются над карточкой, а видео продолжается за ней.
- Прозрачность применяется к единственному фону панели, без классической заливки под градиентом. Исправлены светлый и тёмный режимы, а также фон строк. На Windows в теме «Контур» также доступна настройка прозрачности и сохраняется её значение.
- Название варианта описания: «Справа» / “Right” / “右侧”. Сохранённый выбор расположения продолжает работать.
- Изображения в нижней карточке: кадр EPG → кадр TMDB → постер TMDB. При ошибке загрузки кадра автоматически пробуется следующий источник. Загруженное вертикальное изображение сохраняет пропорции: высота как у кадра, ширина по пропорциям постера, текст начинается через 12 dp. Это применяется и к карточкам фильмов медиатеки. Если подходящего изображения нет, показывается обозначение отсутствия изображения.
- Поиск TMDB по-прежнему выполняется для открытой карточки, с задержкой при быстрой навигации. Сохраняются PIN-защита, локализация и описание провайдера.

Первое нажатие вправо показывает краткую панель со значками и скрытием по настройке; второе раскрывает постоянное описание. На паузе панель остаётся видимой. Эти правила сохранены.

Установка APK поверх предыдущей версии сохраняет настройки. APK — оптимизированная release-сборка с прежним тестовым сертификатом подписи. Windows: распаковать весь архив и запустить `TVNext/TVNext.cmd`; Java включена.

Проверки охватывают размеры реальной области видео при обоих положениях описания, видимость правого описания на 960×540, ширину программ, фокус программ и дат, прозрачность обоих цветовых режимов, переход от недоступных кадров к вертикальному постеру и сохранение настроек после перезапуска. UI выполняется под Linux/Xvfb; физический TCL и запуск Windows здесь недоступны. TMDB проверяется с тестовым сервером/данными, поскольку доступ к его серверам из облака ограничен.

Снимки интерфейса используют тестовое расписание и условную иллюстрацию, а не настоящий кадр фильма.
