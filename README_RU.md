# TVNext 0.2.4 — постеры медиатеки, даты EPG и данные фильмов

Изменения общие для Android TV и Windows; обе темы сохранены.

- В Android-медиатеке запущенный фильм сохраняет постер из каталога после возврата к сетке. Рабочий постер больше не заменяется недоступным URL из TMDB. Если основной источник картинки не отвечает, используется запасной; этот механизм также работает в карточках информации о фильме на Windows.
- При перемещении по передачам нужная дата автоматически выделяется и прокручивается в столбце дней. Фокус остаётся на передаче; вправо можно перейти на уже выбранную дату. Проверен переход через полночь вперёд и назад, в классической и крупной темах.
- Карточка «Описание» в каналах и сведения о выбранной передаче в широком списке загружают описание фильма и постер из TMDB. Настоящее описание провайдера сохраняется; TMDB дополняет отсутствующий текст, включая случаи, когда в EPG буквально написано «Описание отсутствует». Загрузка выполняется для открытой карточки, с задержкой 400 мс при листании, без массового поиска всего EPG. Когда карточка закрывается, её запрос отменяется, если он не нужен другой открытой карточке.
- Поиск сопоставляет точное название и год, если он указан в EPG. Для новостей, погоды, спорта и серий сериалов подбор фильма не выполняется. Если подходящий фильм не найден, чужой сюжет не подставляется. Названия с числами, например «2012» и «Бегущий по лезвию 2049», сохраняются целиком.
- Кэш данных фильма общий для повторных показов на разных каналах и сохраняется в базе. Успешные ответы сохраняются на 7 дней, отсутствие совпадения — на сутки, временная ошибка сети — на минуту, чтобы загрузка могла восстановиться без очистки всего кэша.

Для описаний должен быть включён TMDB в настройках «Фильмы / TMDB» (по умолчанию включён). Откройте карточку «Описание» у передачи. Сервис должен быть доступен с устройства, а фильм должен присутствовать в его каталоге. В узком списке передач отдельная колонка описания, как и раньше, скрывается; описание доступно из панели просмотра.

Android: release 0.2.4, versionCode 6, отладка выключена, код и ресурсы оптимизированы. Сертификат подписи тот же тестовый, что у ранее выданных сборок: установите APK поверх предыдущей версии, без удаления приложения и данных.

Windows x64: распакуйте весь архив .7z с помощью 7-Zip или совместимого архиватора и запустите TVNext/TVNext.cmd. Встроены Java 21, mpv и Vulkan Loader. Отдельная установка Java не нужна. Пользовательские настройки и данные остаются в %USERPROFILE%\.tvnext.

Проверено 104 теста: 42 каналов/интерфейса, 2 медиатеки с проверкой пикселей постера, 14 TMDB, 6 настроек и 40 Android-плеера. Интеграционные тесты TMDB используют тестовый HTTP-движок Ktor и настоящую SQLite-базу: проверены точное совпадение, год, исключение похожих фильмов, кэш повторного показа, выключенный сервис и восстановление после ошибки сети. UI-тесты выполнены на Linux/Xvfb. На физическом TCL и Windows-компьютере сборка не запускалась; подключение к реальному TMDB из этой облачной среды недоступно.

Подпись, версия и флаг отладки APK проверены отдельно. Windows-архив проверен командой 7z t; содержимое JAR сохранено при перепаковке. SHA256SUMS содержит контрольные суммы файлов.
