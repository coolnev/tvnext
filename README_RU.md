# TVNext 0.5.1 для Windows x64

[Скачать portable 0.5.1](https://github.com/coolnev/tvnext/raw/refs/heads/artifacts/windows-0.5.1-20261026/TVNext-0.5.1-windows-x64-portable.7z)

Распакуйте весь архив через 7-Zip и запустите `TVNext.cmd` из папки `TVNext`. Java 21 и mpv уже включены. Настройки и история сохраняются в `%USERPROFILE%\.tvnext`.

## Изменения

- Данные текущей передачи, описание и обложка обновляются в оконном и полноэкранном просмотре. В архиве учитывается позиция просмотра. Просмотр телепрограммы другого канала не подменяет данные воспроизводимой передачи.
- Исправлена повторная загрузка изображений после отмены запроса при закрытии панели. Добавлены повторные попытки при временных сетевых сбоях и запасной официальный адрес изображений TMDB. Ограничены размер ответа и память кеша.
- В полноэкранном режиме список каналов, программы и описание закрываются вместе после ухода мыши. При управлении клавиатурой списки остаются открытыми; Escape закрывает их вместе. В оконном режиме телепрограмма не скрывается по таймеру.
- Выбор канала из поиска по Enter или щелчком убирает фокус из поля ввода и возвращает управление плееру. Стрелка вниз переводит к результатам; Ctrl+F открывает поиск. Повторный выбор текущего канала из поиска не перезапускает его.
- Ввод текста больше не вызывает паузу, перемотку или глобальные команды по буквам. Проверены Escape, F11, пробел и переход между мышью и клавиатурой в каналах и медиатеке.

Все 304 автоматических теста прошли. Проверки выполнялись на Linux: общий Compose-интерфейс, реальные HTTP-запросы к локальному тестовому серверу, загрузка и декодирование картинок, логика EPG/архива, управление плеером и сборка Windows. Общие изменения также прошли компиляцию для Android. Воспроизведение и доступность серверов TMDB на физическом компьютере Windows требуют проверки на устройстве.

Android APK в этом выпуске не обновляется; доступна версия 0.5.
