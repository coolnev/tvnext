# TVNext 0.5.9 — ТВ-гид Windows и изображения передач

## Windows: ТВ-гид

- Категории выбираются мышью; список каналов сразу фильтруется.
- Доступны кнопки −7/−1/Сегодня/+1/+7 дней и обновление EPG.
- Стрелки вверх/вниз выбирают канал, влево/вправо — предыдущую/следующую передачу. Page Up/Page Down меняют день. Enter запускает выбранную текущую передачу или доступный архив; Escape возвращает назад.
- Щелчок по текущей передаче включает канал, по доступной прошедшей — архив. Для будущей передачи показываются сведения и кнопка напоминания.
- Названия каналов остаются слева при горизонтальной прокрутке времени; сетку можно перемещать перетаскиванием, шкалу времени — прокруткой.
- Выбранная передача отображается в отдельном описании под сеткой. При обновлении EPG выбор сохраняется, если эта передача остаётся в программе.
- При открытии прокрутка переходит к просматриваемому каналу. Список запрашивает EPG по настоящим идентификаторам видимых каналов.

## Изображения передач: Windows и Android

В оконном и правом описаниях использовался только постер TMDB. Кадр TMDB и изображение XMLTV не участвовали в загрузке: при недоступном постере карточка оставалась без картинки, даже когда адрес кадра был известен.

Теперь эти варианты, как и нижняя карточка, используют изображение XMLTV, кадр TMDB и постер как запасной вариант. Загруженная картинка сохраняется при обновлении метаданных той же передачи. При переходе на другую передачу прежняя картинка сбрасывается. Если все источники недоступны, пустого квадрата и отступа не появляется.

Добавлена проверка на примере названия «Орел девятого легиона»: различие «е/ё» и регистра не мешает точному сопоставлению названия. Тест показа проверяет пиксели изображения в оконном и правом описаниях при отказе постера; это локальный сценарий, а не проверка реального ответа TMDB для данного канала.

## Соединение TMDB в Windows

Системный curl сам не читает настройки прокси Windows. При запуске через новый TVNext.cmd или сборку Compose включён системный выбор прокси JVM; выбранный HTTP/SOCKS-прокси передаётся загрузчику TMDB и изображений. Настройки системы не изменяются. Прокси опрашивается для каждого запроса, ключ TMDB ему не передаётся при выборе маршрута. Сами HTTP-запросы выполняются обычным образом через выбранный прокси.

Добавлен локальный сетевой тест: запрос к недоступному напрямую имени проходит через выбранный прокси. Не требуется удалять кэш приложения.

Это исправляет поддержку системного прокси, но не доказывает устранение периодических отказов соединения на конкретном компьютере. VPN в виде расширения браузера не предоставляет соединение другим приложениям. Прямое подключение, прокси, доступность TMDB и CDN на компьютере пользователя здесь физически не проверялись.

В терминале Windows теперь различаются этапы: `ProgrammeMetadata ... FOUND` означает наличие метаданных с адресами; `Artwork stage=decode` — декодирование скачанных байтов; `Artwork stage=display` — установка готовой картинки в область ненулевого размера. Ошибка загрузки продолжает повторяться с ограниченными интервалами, пока карточка открыта. Полные адреса потоков и ключи в этих сообщениях не выводятся.

## Отмена запросов EPG

Отмена устаревшего запроса при смене канала/даты теперь распространяется как отмена и в Windows. Она не попадает в обработчик ошибки и не очищает состояние более нового запроса. Это устраняет ложные сообщения `Failed to load EPG` с `JobCancellationException` при обычной навигации. Настоящие ошибки EPG продолжают обрабатываться.

Защита EPG из 0.5.8 сохранена: проверка покрытия сегодняшнего дня для всех известных каналов, повторное обновление неполного источника, сохранение предыдущей программы при оборванном XMLTV и изоляция источников разных плейлистов.

## Установка

**Windows:** распакуйте весь `TVNext-0.5.9-windows-x64-portable.7z` в новую папку и запустите **TVNext.cmd** из неё. В архиве находятся Java 21 и mpv. Пользовательские настройки, плейлисты и кэш хранятся отдельно в `%USERPROFILE%\.tvnext` и сохраняются.

**Android:** установите `TVNext-0.5.9-release.apk` поверх предыдущей версии. Версия 0.5.9, код 23; релизная конфигурация с минификацией, без debuggable. Подпись тем же тестовым сертификатом, что и предыдущие APK; это не отдельный приватный релизный ключ владельца. Включены arm64-v8a, armeabi-v7a, x86, x86_64.

Пройдены 398 проверок без ошибок и пропусков, включая шесть новых сценариев ТВ-гида. Проверена кодировка исходников и сборка обоих приложений.

Локальные проверки выполняются в Linux/Xvfb; Windows HTTP проверяется системным curl на локальных серверах, интерфейс — Compose-тестами с мышью, клавиатурой и проверкой изображения. Физический телевизор Android, Windows с Schannel, каналы провайдера и маршрут пользователя к TMDB в этой среде не проверялись. Контрольные суммы файлов — в SHA256SUMS.
