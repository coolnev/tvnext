# TVNext 0.5.10 — настройки, пропорции видео и часы

## Навигация по настройкам

Исправлен сброс открытого раздела/подраздела на «Общие» при восстановлении фокуса Android. Получение фокуса строкой раздела теперь само по себе не меняет открытую страницу. Навигация выполняется при явном выборе, нажатии OK/Enter, стрелки вправо либо вверх/вниз в списке разделов.

У Android-кнопок удалена лишняя вложенная точка фокуса. Пульт активирует кнопку при отпускании OK, а нажатие и удержание не вызывает повторных открытий. После закрытия окна выбора фокус восстанавливается в текущем разделе; запоздавшие запросы фокуса отменяются.

## Соотношение сторон — Android и Windows

**Настройки → Воспроизведение → Соотношение сторон.**

Режимы: **Автоматически** (первый пункт и значение по умолчанию), **Растянуть на экран**, **16:9, 4:3, 16:10, 21:9, 14:9, 5:4, 3:2, 1:1, 9:16, 1.85:1, 2.35:1, 2.39:1, 2.40:1**.

Выбор действует на воспроизведение каналов, архивов и фильмов, применяется без перезапуска потока и сохраняется после перезапуска приложения. Это общая настройка воспроизведения. Автоматический режим восстанавливает пропорции из видеопотока, а фиксированные режимы переопределяют их. Возврат к «Автоматически» снимает переопределение. «Растянуть на экран» заполняет область видео и может изменять пропорции.

На Android исправлен учёт прямоугольных пикселей при программном декодировании: Media3 DecoderVideoRenderer передаёт размеры кадра без исходного sample aspect ratio. Отображение теперь использует сведения видеодорожки, когда размер выходного кадра ещё совпадает с закодированным. Повторная коррекция уже исправленного размера не применяется. Обычные передачи 4:3 остаются 4:3.

Для Eorolux Cinema рекомендуется сначала проверить «Автоматически», затем при некорректных данных самого источника выбрать **16:9**. Реальный поток этого канала на телевизоре TCL здесь не проверялся; найденная ошибка декодера воспроизведена на данных кадров 1440×1080 и 720×576 с прямоугольными пикселями.

На Windows настройка передаётся в mpv, включая снятие ручного переопределения и восстановление выбранного режима после загрузки следующего файла. Проверено, что изменение не запускает фильм заново, не меняет позицию и не снимает паузу.

## Часы без фона — Android и Windows

**Настройки → Оформление → Часы без фона.**

Новая отдельная опция сохраняется независимо от положения часов. При включении остаются белые цифры с небольшой тенью для читаемости на видео; подложка не рисуется. Размер и положение часов сохраняются. При выключении возвращается прежняя подложка. Если часы отключены в пункте «Часы на экране», эта опция сама их не включает.

## Установка

- **Android:** `TVNext-0.5.10-release.apk`, версия 0.5.10, код 24. Release без debuggable, с минификацией и прежней тестовой подписью. Устанавливается поверх предыдущих тестовых версий без удаления настроек. Включены arm64-v8a, armeabi-v7a, x86, x86_64.
- **Windows x64:** распакуйте весь `TVNext-0.5.10-windows-x64-portable.7z` в новую папку и запустите `TVNext.cmd`. Java 21 и mpv включены. Данные остаются в `%USERPROFILE%\.tvnext`.

Сохраняются изменения 0.5.9: ТВ-гид Windows, источники кадров и постеров, учёт системного прокси Windows для Happ, обработка отмены запросов EPG. Очистка кэша и сброс данных для обновления не нужны.

## Проверка

Пройдены 413 проверок без ошибок и пропусков.

Проверки выполнены в Linux/Xvfb: управление настройками с обработчиком TV-пульта, восстановление фокуса, выбор всех режимов соотношения сторон, сохранение настроек в SQL, автоматическая коррекция прямоугольных пикселей, команды настоящего контроллера mpv с подменённым native API, а также сравнение пикселей часов с подложкой и без неё. Android и Windows собраны; Windows-архив проверен на целостность и сохранение данных JAR-файлов.

Физическое воспроизведение конкретного канала на TCL и запуск Windows здесь не проверялись. Контрольные суммы находятся в SHA256SUMS.
