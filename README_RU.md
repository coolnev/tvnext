# TVNext 0.5.20 — Android

Добавлены фоновая запись и запись по расписанию из EPG.

- В ТВ-гиде откройте передачу и выберите «Запланировать запись». В списке программ будущая передача открывает окно планирования по OK. Можно задать запас времени до начала и после окончания.
- «Главная → Мои записи → Расписание» показывает планы выбранного профиля и позволяет отменить запись. При отмене начатой записи сохранённая часть остаётся доступной.
- «Настройки → Запись»: папка хранения, общий лимит места, стандартный запас времени и системные разрешения. По умолчанию: 2 минуты до начала, 5 минут после, 4 ГБ. Старые файлы не удаляются автоматически.
- Папку можно выбрать через системный проводник, включая доступный накопитель. Старые записи сохраняют прежнюю папку. Накопитель должен оставаться подключённым и доступным для записи.
- Запись продолжается при свёрнутом приложении и управляется через уведомление. Одновременно записывается один канал; расписание учитывает пересечения, включая запас времени. Плановая запись завершает текущую ручную запись перед запуском.
- Расписание и файлы принадлежат создавшему их профилю. Плановая запись может работать в фоне при другом активном профиле, не переключая текущий канал. При смене профиля ручная запись завершается, как раньше.
- После перезапуска приложения или устройства будущие планы восстанавливаются. Прерванная начатая запись автоматически заново не запускается; сохранённая часть остаётся в «Моих записях».
- Новые пункты переведены на русский, английский и китайский.

## Условия работы

Android-устройство должно быть включено и иметь доступ к источнику. Запись не может включить выключенный телевизор. Android 12 и новее может потребовать разрешение на точные сигналы; приложение предлагает его при планировании. Принудительная остановка приложения и ограничения производителя могут помешать запуску: после принудительной остановки откройте приложение снова.

Одна ручная запись ограничена 2 часами, плановая — 6 часами с учётом запаса. Android 15 и новее дополнительно ограничивает суммарное время фоновой службы передачи данных; при системной остановке приложение сохраняет уже записанную часть. Предел зависит от версии Android и состояния приложения.

Поддерживаются MPEG-TS и HLS со встроенным звуком, в том числе AES-128 и fMP4. HLS с отдельной аудиодорожкой пока не поддерживается. Воспроизведение записи работает из выбранной папки; экспорт создаёт ZIP с локальным плейлистом и медиафайлами.

APK: релизная сборка, versionCode 34, четыре архитектуры, прежняя подпись. Windows в этой версии не обновлялась.

Проверка: автоматические тесты и Android-эмулятор. Проверка на физическом TCL в этой среде недоступна.
