# TVNext 0.5

Android TV: версия 0.5, versionCode 14. Windows: версия приложения 0.5; служебная версия установочного пакета 0.5.0 соответствует формату Windows.

## Оконный режим «Контура»

- Исправлено принудительное открытие полноэкранных списков при переходе в оконный режим. Короткое OK при просмотре прямого эфира открывает видео в отдельном окне рядом со списком, как в классической теме. В Windows в «Контуре» это также доступно через Enter; L переключает режим, как прежде.
- Окно плеера оформлено рамкой и поверхностями «Контура»; доступны обычные элементы управления. Нижнее описание располагается отдельно от окна и списка, не закрывая выбранный канал и кнопки.
- Стрелка влево в полноэкранном просмотре открывает списки поверх полноэкранного видео. Для этого варианта сохраняются широкие списки и описание снизу либо справа без уменьшения видео.
- Оконная панель программ имеет ограниченную ширину и не вытесняет плеер. Проверены фокус текущего канала и архивной программы, переходы программы → даты → программы → каналы, оба положения описания и возврат к полноэкранному видео. Короткое OK в полноэкранном архиве с ТВ-гидом сохраняет функцию паузы/продолжения.

## Почтовые отчёты EPG удалены

Удалены оба почтовых отправителя EPG, общий/платформенные интерфейсы отправки, встроенные данные отправителя и автоматический наблюдатель ошибок EPG при запуске Android. Обновлённое приложение не вызывает почтовый API. Обычная телепрограмма и локальные средства диагностики плеера не отправляют почту.

## Номер версии

Номер берётся из `tvnextVersionName` в `gradle.properties`. Android-метаданные, Windows-метаданные, раздел «О приложении» и подпись версии в интерфейсе согласованы. Общий `AppVersion` генерируется при сборке, чтобы надписи на платформах не расходились. Ссылки на текущую Android-сборку обновлены; прежние заметки о выпусках остаются историей.

## Установка и проверка

Android: установите `TVNext-0.5-release.apk` поверх предыдущей версии. Это оптимизированная release-сборка без отладки, с прежним тестовым сертификатом подписи и сохранением настроек.

Windows: закройте приложение, распакуйте весь `TVNext-0.5-windows-x64-portable.7z` и запустите `TVNext/TVNext.cmd`. Java и библиотеки воспроизведения включены. Профиль пользователя хранится в `%USERPROFILE%\.tvnext`.

Проверки включают разные действия OK/Enter и стрелки влево, реальные размеры окна видео, отсутствие перекрытия выбранного канала и кнопок нижним описанием, навигацию архива и дат, отсутствие почтового API/отправителей и их ключей в новой APK, согласованность версий, прежнюю подпись и целостность Windows-архива.

UI проверен в Linux/Xvfb с тестовым расписанием. Физический TCL и запуск под Windows здесь недоступны. На снимке оконного режима тестовый контроллер не воспроизводит настоящий поток, поэтому само окно видео чёрное.
