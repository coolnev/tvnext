# TVNext 0.5.27

Android TV, versionCode 41. Основа — оригинальный APK 0.5.21. Версия 0.5.22 и старый проект 0.2 не использовались. Подпись сохранена, APK устанавливается обновлением.

- Списки категорий, каналов, передач и дней слева используют всю высоту экрана. Размер видео справа постоянный.
- Полный ряд управления находится непосредственно под видео и остаётся видимым при переходах между списками.
- Под видео и управлением расположены описание и три следующие передачи: время начала–окончания и название.
- OK воспроизводит выбранный канал. Вправо: каналы → передачи → дни → управление. Если дат нет, переход к управлению идёт из программы передач.
- Полноэкранный гид по нажатию влево занимает весь экран: каналы, передачи и даты. Строки и отступы уплотнены; на экране 720p видно семь каналов.
- В прогрессе и описании сохранены небольшие боковые отступы текста.
