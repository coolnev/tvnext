# TVNext Android 0.5.17 — исправление запуска

[Скачать release APK](https://github.com/coolnev/tvnext/raw/refs/heads/artifacts/release-0.5.17-20261027/TVNext-0.5.17-release.apk)

В 0.5.16 новый плеер начинал миграцию профилей на главном потоке, а MainActivity синхронно ожидала загрузки тех же данных. Миграция удерживала блокировку, но для её завершения требовалось вернуть управление главному потоку. Получалась взаимная блокировка до появления главного экрана. Очистка данных не устраняла причину и повторяла первый запуск.

В 0.5.17 из MainActivity удалены блокирующие ожидания. Репозитории и первый профиль загружаются асинхронно в фоновом потоке, после этого создаётся владелец воспроизведения и основной интерфейс. Декодер из сохранённых настроек устанавливается до создания плеера. Во время загрузки отображается небольшой индикатор. Обработка ухода в фон и возврата учитывает, что плеер может быть ещё не готов; незавершённая загрузка не перезаписывает сохранённую сессию пустыми значениями.

Если инициализация завершится ошибкой, приложение показывает возможность повторить запуск или закрыться. Оно не сбрасывает профили и не требует очистки данных.

Новые функции 0.5.16 сохранены:

- Настройки → Общие → Профили.
- Настройки → Плейлисты и EPG → Редактор каналов.
- Настройки → Воспроизведение → Индивидуальные настройки каналов.
- Настройки → Обслуживание → Резервная копия профилей.
- Кнопка ↶ на нижней панели — предыдущий канал.

Родительская защита общая для профилей. Платёжная блокировка не добавлялась. Таймера сна нет. Запись, локальный Timeshift, облако и мультипросмотр остаются следующими этапами.

Release APK: versionCode 31, минификация, отладка отключена, прежняя подпись. Устанавливается поверх 0.5.16 или более ранней версии. Повторно удалять приложение или очищать данные не нужно. Уже удалённые пользователем данные эта сборка восстановить не может.

Регрессионная проверка отдельно воспроизводит старую взаимную блокировку и подтверждает завершение асинхронного запуска на пустой базе и с ранее выбранным профилем. Все 661 автоматическая проверка прошли без ошибок и пропусков.

Дополнительно проверен именно минифицированный release APK на Android 10 / API 29, x86_64, в эмуляторе: обновление поверх 0.5.16, запуск после очистки данных, открытие настроек и повторный запуск процесса. Во всех этих случаях основной интерфейс открылся, ошибок запуска в журнале не было. На том же эмуляторе у 0.5.16 воспроизведён чёрный экран. Физический TCL не проверялся; это не проверка воспроизведения потоков или работы аппаратного декодера.

Windows не пересобиралась и остаётся на 0.5.10. Проблема аппаратного воспроизведения EuroLux VIP 4K60FPS этим исправлением не решается.
