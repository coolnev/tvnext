# TVNext 0.5.21 — Android

Исправлена работа с папками и экспортом на Android TV без системного проводника, а также кнопка уведомлений записи.

- «Настройки → Запись → Выбрать папку» предлагает выбор совместимого приложения, включая сторонние проводники с поддержкой выбора папки. «Выбрать без проводника» открывает встроенный список: внутренняя папка, папка TVNext в памяти устройства и подключённые накопители, к которым Android предоставляет приложению доступ. Установленный по умолчанию проводник больше не подставляется автоматически: используется окно выбора совместимого приложения.
- Встроенные папки на накопителях принадлежат приложению и удаляются при его удалении. Для независимой копии готовой записи используйте «Сохранить в файл». Смена папки по-прежнему применяется только к новым записям; старые записи остаются на прежнем месте.
- «Мои записи → Сохранить в файл» предлагает «Выбрать приложение для сохранения» и также позволяет создать ZIP прямо в «Загрузки / TVNext», без системного проводника. После завершения показано место сохранения. Можно также выбрать папку TVNext на доступном накопителе.
- На Android 10 и новее экспорт в «Загрузки» использует MediaStore без разрешения на доступ ко всем файлам. На Android 7–9 может потребоваться разрешение на запись. Если системное хранилище недоступно, приложение использует свою папку экспорта и показывает её фактический путь.
- При ошибке или отмене экспорта исходная запись сохраняется. Незавершённая копия, созданная самим приложением, удаляется.
- Раздел записи показывает, включены ли уведомления. Кнопка «Настроить уведомления записи» показывает статус и позволяет перейти в настройки Android. На Android 13 и новее при необходимости запрашивается разрешение; на более старых версиях отдельного запроса этого разрешения нет.
- Сохранены принадлежность записей профилям, фоновая запись, расписание, предыдущая подпись APK и настройки пользователей.

На некоторых телевизорах Android не предоставляет доступ к USB через папки приложения. В таком случае для произвольной папки USB нужен работающий системный выбор папки; встроенный список показывает только действительно доступные накопители.

Если совместимого приложения нет, появляется предложение установить бесплатный AnExplorer для Android TV (с рекламой), повторить проверку или продолжить без проводника. Установка выполняется только по нажатию пользователя через магазин. Cx и другие проводники показываются для тех действий, которые они предоставляют системе. Обычный просмотр файлов не означает поддержку выбора папки с разрешением на запись.

Сборка: Android 0.5.21, versionCode 35, релизная APK, четыре архитектуры. Windows не обновлялась.
