# TVNext Android 0.5.16

Первый этап дополнительных возможностей для будущей TVNext Pro. Все новые функции в этой сборке доступны без оплаты. Таймер сна не добавлялся. Windows остаётся на версии 0.5.10.

[Скачать release APK](https://github.com/coolnev/tvnext/raw/refs/heads/artifacts/release-0.5.16-20261027/TVNext-0.5.16-release.apk)

## Профили

Настройки → Общие → Профили. Можно создать до восьми профилей, выбрать, переименовать и удалить неактивный профиль.

У каждого профиля свои избранные каналы и фильмы, история, позиции фильмов, последний канал, оформление, язык интерфейса и персональный список каналов. Текущее избранное, история и оформление автоматически переносятся в «Основной». При переключении профиля воспроизведение останавливается; следующий просмотр использует данные выбранного профиля. Сохранение позиции фильма, завершившееся после переключения, относится к прежнему профилю.

Плейлисты, сетевые настройки и настройки воспроизведения по умолчанию общие. Родительская защита тоже общая; новый профиль не отключает её. Правильный PIN продолжает открывать защищённые каналы до закрытия приложения.

## Редактор каналов

Настройки → Плейлисты и EPG → Редактор каналов. Доступен поиск, изменение названия и категории, скрытие/возврат канала, избранное и перемещение выше/ниже. В поле категории можно ввести своё название. Опция скрытия дубликатов убирает каналы с полностью одинаковым адресом потока.

Изменения сохраняются отдельно от источника и переживают обновление плейлиста при сохранении идентификаторов каналов. Новые каналы провайдера появляются автоматически. Скрытые и дублирующиеся каналы остаются доступны в редакторе. Исходное имя и категория используются для EPG и родительского контроля независимо от переименования.

«Вернуть список провайдера» после подтверждения восстанавливает названия, категории, порядок и видимость только в текущем профиле. Избранное и индивидуальные параметры воспроизведения сохраняются. Отдельно можно сбросить настройки одного канала.

## Параметры отдельного канала

Настройки → Воспроизведение → Индивидуальные настройки каналов. Этот же экран доступен через редактор.

- Соотношение сторон: все существующие варианты, включая «Автоматически» и наследование общих настроек.
- Декодирование: автоматически, аппаратное, программное или наследование общих настроек.
- Предпочтительный язык звука.
- Предпочтительный язык субтитров, автоматический режим или отключение.

Выбор применяется к каналу и его архиву. Следующий канал использует свои параметры, медиатека — общие. Язык применяется, если соответствующая дорожка есть в потоке; это не перевод звука. Отдельная регулировка задержки звука и выбор конкретной дорожки среди нескольких дорожек одного языка в этот этап не входят.

Кнопка пропорций на нижней панели Android теперь запоминает выбор для текущего канала и профиля. Изменение пропорций не перезапускает поток. Изменение декодера требует пересоздания плеера; архив сохраняет позицию.

## Резервная копия и предыдущий канал

Настройки → Обслуживание → Резервная копия профилей. Android предлагает выбрать файл через системное окно. Сохраняются профили, избранное, история, позиции фильмов, оформление и изменения каналов. Адреса источников, API-ключи и родительские реквизиты не экспортируются. На другом устройстве предварительно добавьте те же источники. При восстановлении все профили заменяются после подтверждения; некорректный файл не меняет текущие данные. На телевизоре нужен системный компонент выбора файлов.

На нижней панели просмотра появилась кнопка ↶ «Предыдущий канал». Она возвращает между двумя последними каналами, соблюдая родительский контроль. История этой кнопки сбрасывается при смене профиля.

Новые страницы и сообщения переведены на русский, английский и китайский. Выбор пропорций/декодирования/языка в редакторе открывается с фокусом на текущем варианте; стрелки вверх/вниз прокручивают список.

## Проверка и ограничения

Release APK: versionCode 30, минификация, отладка отключена, прежняя подпись для установки поверх предыдущих сборок. **658 автоматических проверок** без ошибок и пропусков. Автотесты проверяют перенос существующих данных, профили, резервную копию, сохранение EPG/защиты после переименования, параметры воспроизведения, клавиатуру и фокус, а также предыдущие исправления. Физического Android TV среди тестовых устройств нет; аппаратное воспроизведение и системный файловый диалог требуют проверки на телевизоре.

EuroLux VIP 4K60FPS не объявляется исправленным: реальный поток недоступен из облачной среды, причина отказа аппаратного декодера не установлена. Порядок автоматического восстановления из 0.5.14 сохранён.

Запись по расписанию, локальный Timeshift для каналов без архива, облачная синхронизация, мультипросмотр и платёжная разблокировка ещё не реализованы. Продолжение VOD и напоминания уже существовали; в этом этапе позиции VOD разделены между профилями. Объединённая лента продолжения архивных передач и расширенные напоминания остаются следующими этапами.
