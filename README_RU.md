# TVNext 0.2.6 — языки интерфейса и настройки

Для Android TV и Windows x64.

## Что изменилось

- **Настройки → Оформление → Язык интерфейса**: Русский, English, 简体中文 (упрощённый китайский). Язык применяется без перезапуска и сохраняется после закрытия приложения. Существующие установки сохраняют русский язык, пока пользователь не выберет другой.
- Переведены разделы приложения, настройки и значения параметров, поиск, медиатека, элементы управления плеером, родительский контроль и окна PIN, сообщения об ошибках, календарные даты и дни недели. Каталоги содержат 480 строк для английского и китайского языков.
- Названия каналов, категории и тексты программ, полученные от IPTV-провайдера, остаются исходными. Приложение не отправляет их в сервис автоматического перевода.
- Описания и жанры TMDB запрашиваются на выбранном языке. При отсутствии перевода возможен текст на другом доступном языке. Кэш разделён по языкам; старый русский кэш сохранён. Запросы, начатые до переключения, не подменяют данные нового языка.
- Китайский шрифт Noto Sans CJK SC включён в сборки; набор содержит все китайские символы интерфейса. Лицензия SIL Open Font License включена в ресурсы приложения.
- **Общие → Блоки главной страницы**: количество карточек и видимость блоков стартовой страницы. Этот пункт перенесён из оформления и получил более точное название.
- В **Медиатеке** параметры API-ключа TMDB доступны непосредственно на странице. Лишний пункт «Дополнительно» удалён.
- Пояснение в «О приложении» следует выбранному языку. Русский текст: «Приложение использует API TMDB, но не одобрено и не сертифицировано TMDB». Это уведомление об использовании сервиса, а не ошибка подключения.
- Обе темы сохранены. Родительская защита продолжает открывать все защищённые каналы после одного правильного PIN до закрытия приложения.

## Установка

**Android:** скачайте `TVNext-0.2.6-release.apk`, разрешите установку из выбранного источника и установите поверх текущего TVNext. Это release-сборка: без отладки, с оптимизацией и сокращением кода. Она подписана тем же тестовым сертификатом, что и предыдущие сборки; удалять старую версию для обновления не требуется.

**Windows x64:** закройте приложение, полностью распакуйте `TVNext-0.2.6-windows-x64-portable.7z` и запустите `TVNext/TVNext.cmd`. Включены Java 21, mpv и необходимые DLL; отдельно устанавливать Java не требуется. Настройки и история находятся в `%USERPROFILE%\.tvnext` и сохраняются при замене папки программы.

## Проверка

Проверены общая UI-версия под Linux/Xvfb, переключение всех трёх языков, сохранение настройки в SQLite, даты, полнота словарей и аргументов, отображение китайского шрифта, окна PIN, раздельный кэш TMDB, прежние тесты навигации, архива, медиатеки и плеера. Снимки настроек сняты с работающего общего интерфейса.

Сборки проверены по версии, подписи, составу и контрольным суммам; архив Windows проверен командой `7z t`. Физический телевизор TCL и запуск Windows в этой облачной среде недоступны. Запросы TMDB проверены с имитацией API; проверка реального сервиса требует доступа с устройства пользователя.
