# TVNext 0.2.8 — «Контур», описание снизу и информация о программе

Для Android TV и Windows x64.

## Включение и возврат прежнего вида

**Настройки → Оформление → Тема → Контур.** Тема добавлена отдельным вариантом: объёмные тёмные окна, белые рамки, градиенты, мягкие тени и выделение активной строки. Классическая и крупная темы сохранены. Выбранная раньше тема не сбрасывается при обновлении.

**Настройки → Оформление → Описание передачи**:
- **Снизу во всю ширину** — новый вариант по умолчанию;
- **Сбоку · прежний вариант** — возврат к прежнему расположению.

Расположение описания не зависит от выбранной темы. Для полного возврата прежнего оформления выберите прежнюю тему и расположение сбоку. Обе настройки сохраняются после перезапуска, остальные данные приложения сохраняются.

## Описание и изображение

- Под списками категорий, каналов, программ и дат находится общая карточка. Она показывает выделенную передачу; при переходе по датам содержание меняется вместе с выделением.
- В архиве карточка использует архивную программу. Фокус пульта остаётся в списках, канал и соответствующая передача остаются на одной высоте.
- Слева находится изображение программы из XMLTV или кадр TMDB. При отсутствии/ошибке загрузки кадра используются постер TMDB и доступное изображение медиатеки. Если изображения нет ни в одном источнике, показывается явное обозначение его отсутствия.
- Новая компактная карточка также используется в раскрытом описании и в медиатеке. В небольшом окне изображение и значки перестраиваются, чтобы не перекрывать заголовок.
- Метаданные XMLTV (изображение, возраст, качество, звук) сохраняются в компактном кэше EPG и переживают перезапуск. Старый кэш остаётся читаемым. Чтобы сразу получить новые поля от провайдера, обновите телепрограмму в «Плейлисты и EPG → Телепрограмма → Обновить сейчас».
- Кадры не существуют для каждой передачи: их наличие зависит от XMLTV/TMDB. TMDB поддерживает прежде всего фильмы; для новостей и других передач используются картинки провайдера, если он их публикует.

## Значки

- Разрешение: 4K, 1080p, 720p и другие известные разрешения; HD/SD, если провайдер указал только такую категорию качества.
- Звук: 5.1 и другие известные схемы, стерео и моно. Если известно только число каналов, приложение показывает число каналов, не выдумывая схему расположения колонок.
- Возраст: 0+, 6+, 12+, 16+, 18+ и другие явно указанные ограничения. Приоритет имеет рейтинг XMLTV, затем явная отметка в названии/описании. Неизвестный возраст не подменяется догадкой.
- Диагностика потока используется только для программы, которая действительно воспроизводится. При просмотре будущих/других передач применяются сведения EPG, если они есть; параметры текущего потока не выдаются за параметры другой передачи.

## Быстродействие и родительский контроль

Оформление использует статические градиенты и тени без размытия видео. Кадры TMDB запрашиваются в размере w780; сохраняются задержка запроса при быстром листании, отмена ненужных запросов и существующий кэш изображений. Изображения и описание защищённого канала не запрашиваются до разблокировки PIN-кодом.

Прежние исправления сохранены: раскрытое описание остаётся до закрытия, на паузе панель не исчезает, после продолжения применяется полный интервал из настроек, больших отдельных значков паузы/воспроизведения поверх видео нет.

## Сборки и проверка

Android: установите `TVNext-0.2.8-release.apk` поверх предыдущей версии. Это оптимизированная release-сборка без отладки с тем же тестовым сертификатом, что и предыдущие сборки.

Windows x64: закройте приложение, распакуйте весь `TVNext-0.2.8-windows-x64-portable.7z`, запустите `TVNext/TVNext.cmd`. Java 21 и библиотеки воспроизведения включены. Настройки находятся в `%USERPROFILE%\.tvnext`.

`TVNext-Contour.png` — снимок работающего общего интерфейса с тестовым расписанием и условной тестовой иллюстрацией; в приложении используются изображения из указанных выше источников.

Проверены навигация, выравнивание строк, переходы между датами, сохранение фокуса при возврате к старому виду, приоритеты и запасные источники изображений, значки, сохранение EPG после перезапуска и защита изображений PIN-кодом. UI проверен под Linux/Xvfb, запросы TMDB — с имитацией API. Прямой доступ к TMDB, физический TCL и запуск Windows в этой облачной среде недоступны.
