# TVNext 0.5.12 — Android

Кнопка соотношения сторон перенесена в нижний левый угол информационной панели, на одну линию с кнопками перемотки и паузы. Текущий режим, выбор с пульта и возврат фокуса сохранены.

## Устойчивость описаний

Ранее успешно найденные данные на Android больше не удаляются из кэша из-за временной ошибки сети или пустого результата обновления. После семи дней они показываются сразу, а обновление идёт в фоне. Одновременно допускаются два таких обновления; они не занимают все места в очереди новых запросов. Повторное фоновое обновление одной записи ограничено интервалом в две минуты. Очистка кэша отменяет эти фоновые запросы.

Сохраняются описания и адреса постеров/кадров. Само изображение без сети доступно, если оно осталось в локальном кэше изображений. Для ещё не загруженных данных нужен доступ к внешнему сервису. Изменение не устраняет блокировки или недоступность TMDB у провайдера.

## Резерв Kinopoisk.dev

В Android добавлен раздел «Настройки → Медиатека → Kinopoisk.dev · резерв»: защищённое поле API-ключа и отдельная проверка соединения. Это неофициальный API, которому нужен собственный ключ пользователя. В сборку ключ не включён. Получите его у Kinopoisk.dev и вставьте в приложении; в чат присылать его не требуется. Пустое поле отключает обращения к резерву.

Когда ключ указан, резерв используется при ошибке TMDB или отсутствии подходящего результата. Ожидание основного поиска ограничено десятью секундами, чтобы осталось время обратиться к резерву. Общий срок поиска ограничен двадцатью секундами. Проверяются название, тип произведения и год, если он известен; неоднозначные фильмы разных лет без указанного года пропускаются. Кадры и постеры загружаются по адресам выбранного сервиса; подпись источника соответствует данным.

Ключ передаётся в заголовке только по HTTPS на api.kinopoisk.dev; перенаправления отключены. Проверка соединения различает неверный ключ, отказ доступа, ограничение сервиса и сетевую ошибку. При смене ключа сбрасываются отрицательные результаты поиска, успешный кэш сохраняется.

## Установка и проверка

TVNext-0.5.12-release.apk: версия 0.5.12, код 26. Релизная сборка с минификацией, без debuggable, с прежней тестовой подписью. Включены arm64-v8a, armeabi-v7a, x86, x86_64. Можно установить поверх предыдущей версии без удаления данных.

Проверяются кэш при отказе и зависании сети, ограничение фоновых запросов, переход на резерв, отсутствие запросов без ключа, совпадение фильма, обработка ошибок и запрет перенаправления ключа. Также проверяются сохранение и скрытие ключа в настройках, положение кнопки и управление пультом. Полный прогон: 603 проверки без ошибок и пропусков.

Проверки выполнены на Linux с Xvfb, мок-серверами и Android host-тестами. Физический телевизор не проверялся. Рабочего ключа Kinopoisk.dev нет, поэтому доступ к реальному резервному сервису и лимиты учётной записи не проверены.

Windows в этом выпуске не пересобиралась; опубликованная версия остаётся 0.5.10.
