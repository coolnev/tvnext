# TVNext 0.2.9 — краткая панель, описание и размер шрифта

Для Android TV и Windows x64.

## Панель программы на Android TV

- **Один раз вправо:** компактная панель с текущей передачей и значками разрешения, звука и возраста. При воспроизведении она скрывается через выбранный в настройках интервал — по умолчанию 3 секунды. Таймер теперь применяется и к прямому эфиру, и к архиву; прежде ограничение на режим архива оставляло панель эфира открытой.
- **Второй раз вправо:** раскрывается описание. Оно остаётся открытым до закрытия пользователем.
- Значки показываются сразу в краткой панели и в одном экземпляре при раскрытии. Отдельные старые текстовые строки разрешения/FPS и звука из этой панели убраны. Для краткого и раскрытого вида используется один источник значков.
- На паузе панель остаётся видимой. После продолжения начинается полный интервал скрытия из настроек.
- В Windows информационная панель также использует общий набор значков и программу фактического просмотра, включая архив.

## Темы

- В «Контуре» применена типографика классической темы: на Android — прежний компактный системный шрифт, на Windows — классические размеры. Размеры текста списков программ также приведены к классическому виду.
- Крупная тема удалена из выбора. Доступны **Классическая** и **Контур**.
- Если раньше была сохранена крупная тема, приложение выберет классическую. Язык, цветовой режим, расположение описания, история и остальные настройки сохраняются.
- Белые рамки, поверхности и тени «Контура», нижняя карточка с изображением и переключатель прежнего расположения описания сохранены.

## Установка и проверка

Android: установите `TVNext-0.2.9-release.apk` поверх предыдущей версии. Сборка release, без отладки, с оптимизацией и прежним тестовым сертификатом подписи.

Windows x64: закройте приложение, распакуйте весь `TVNext-0.2.9-windows-x64-portable.7z` и запустите `TVNext/TVNext.cmd`. Java 21 и библиотеки воспроизведения включены. Профиль хранится в `%USERPROFILE%\.tvnext`.

Проверены первое и второе нажатия вправо в эфире и архиве, оба расположения описания, единственный экземпляр значков, длительная пауза, полный 7-секундный интервал после продолжения, совпадение типографики и загрузка сохранённой крупной темы с сохранением остальных настроек. UI проверен под Linux/Xvfb; физический TCL и запуск Windows в облачной среде недоступны.

`TVNext-Contour.png` — снимок работающего интерфейса с новым размером шрифта, тестовым расписанием и условной тестовой иллюстрацией.
