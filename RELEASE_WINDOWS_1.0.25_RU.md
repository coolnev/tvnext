# TVNext 1.0.25 — Windows portable x64

[Скачать один ZIP с GitHub](https://github.com/coolnev/tvnext/releases/download/windows-v1.0.25/TVNext-1.0.25-windows-x64-portable.zip). Распакуйте весь архив, перенесите свою папку `data` из предыдущей сборки рядом с новым **TVNext.exe**, затем запустите приложение. Java и кодеки включены.

В категориях медиатеки появляется **«Избранное»**, когда добавлен хотя бы один фильм. Фильтр показывает избранные фильмы разных жанров, сохраняя выбранный источник, поиск и сортировку. После удаления последнего избранного категория исчезает, а каталог возвращается к обычному списку. Режим фильтра переживает пересоздание окна по F11.

Кнопка избранного увеличена и перенесена в левый верхний угол постера: добавленный фильм отмечен заполненной жёлтой звездой. Щелчок по звезде переключает избранное и не запускает фильм. Под названием отдельной звезды больше нет. Подсказки переведены на английский и китайский.

В полноэкранном списке каналов сверху есть кнопка **«Категории»**. Можно выбрать все каналы, избранные или категорию провайдера поверх видео. Список сбрасывает прежнее положение прокрутки для другой категории; скрытый поисковый фильтр очищается. Выбор канала включает прямой эфир.

Сохранены исправления 1.0.24 r3: раскрытые настройки, ограниченный постер слева от описания, адаптивное верхнее меню, список каналов у левого края, отсутствие случайной паузы эфира, компактная громкость, перемотка архива мышью, отметка эфира и кнопка «В эфир». Каталог и настройки не сохраняют поверх себя видео с другого экрана при анимации.

Все 364 проверки прошли: 17 Desktop, 17 медиатеки, 85 плеера и 245 Android. Проверены появление/удаление категории, фильтрация/сортировка, сохранение избранного после перезагрузки компонента, границы и независимый щелчок по звезде, выбор категории и другого канала без закрытия полноэкранного списка. Использованы настоящее дерево интерфейса с Koin и синтетические источники. 423 файла Windows runtime и сторонних библиотек совпали с проверенным r3. Исходники плеера, EPG и метаданных не менялись. UI проверен на Linux/Xvfb; физический Windows-ПК и HDMI/GPU здесь недоступны.

Исходники — в `main`, теги `v1.0.25` и `windows-v1.0.25`. Сводка и SHA-256: `releases/validation-1.0.25.json`. [Android APK](RELEASE_ANDROID_1.0.25_RU.md).
