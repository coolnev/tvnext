# TVNextR 0.5.44 — Android

Пакет `com.tvnext.app.recovery`, versionCode 544, прежняя подпись; установка поверх 0.5.43. APK `releases/android/TVNextR-0.5.44.apk`. SHA-256 `9c2d1a4ce4729e3095be27ab38de23ae68ba85d3a4ad501c6dd259713be9378e`. Исходники `b780a2aa27d564f4cc2127f93a3c1d71aacf9c96`.

Сообщения о записи теперь показываются внутри приложения только текстом. Убраны системные Toast, в которые Android добавлял значок приложения/робота. Это касается начала записи, запроса остановки, ошибок, требования включить эфир и результата экспорта. «Запись остановлена» появляется после завершения службы через RecordingRuntime.

TextOnlyNotice содержит текст на небольшой тёмной подложке, без картинки и фокусируемых элементов. Сообщение исчезает через 2,8 секунды; новое сообщение перезапускает срок показа, прежний таймер не скрывает новое. Уведомления не меняют текущий фокус пульта. Красный REC сохраняет свою индикацию фактической работы службы.

Пройдены две проверки плеера записей, дополненные показом «Запись начата»/«Запись остановлена» и сохранением фокуса на паузе. Снимок настоящего Compose-интерфейса проверен визуально. Пройдены encoding, release, lintVitalRelease, подпись, ZIP, zipalign и сохранение встроенного ключа. Картинки, значок и прямоугольный баннер Android TV совпадают с 0.5.43.

На физическом телевизоре и в эмуляторе этот APK не запускался; UI-проверка использует тестовое воспроизведение.
