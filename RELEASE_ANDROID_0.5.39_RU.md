# TVNextR 0.5.39 — Android

Пакет `com.tvnext.app.recovery`, versionCode 539, прежняя подпись. Установка поверх 0.5.38 с сохранением настроек и EPG. APK `releases/android/TVNextR-0.5.39.apk`; SHA-256 `f99c667d43b5a4b8ec0c658fb4e12e8475cf4c76c9aa10895c4a6f8499e697de`. Исходники `abb0b67b2c13f54470adb491b949eb0b9e7c2d43`.

Исправлен показ описаний при переключении каналов. Обе поверхности — оконное/полноэкранное описание и подпись гида — используют общий выбор наиболее полного пригодного текста. «Описание нет», «Описания нет», «Нет описания фильма», «Описание: Нет описания» и другие заглушки EPG больше не считаются сюжетом. Короткое описание EPG заменяется найденным полным сюжетом; более полный EPG сохраняется, если он информативнее.

Состояние удалённой карточки привязано к конкретному названию. Новая передача не рисует сюжет предыдущей до запуска LaunchedEffect. При возврате готовая карточка берётся синхронно из кэша с учётом названия/года, затем обновляется асинхронно. Полученный текст сохраняется при временной ошибке или частичном обновлении.

Оконная панель проверяет идентификатор канала для EPG и курсора архива. Пока программа другого канала загружается, больше не подставляется программа играющего канала. Полноэкранная панель также отбрасывает EPG прежнего канала при смене воспроизведения.

«Хитрый койот» используется только как тестовый пример; исправление общее для передач и фильмов. Пройдены шесть UI-сценариев заглушек/короткого EPG с постером до сюжета, проверка состояния в момент смены двух названий и возврате в кэш, четыре проверки выбора EPG/архивного курсора и три проверки выбора текста. Сохранены проверки общего скролла картинки/текста и ровных базовых линий.

Провайдер остаётся `kinopoiskapiunofficial.tech`, dev отключён. Встроенный UUID ключ и проверка соединения сохранены. Пользователь подтвердил успешную проверку соединения на телевизоре; значение ключа в исходники GitHub не добавлено.

Проверки: 42 metadata + 89 channels/UI + 44 native Android API28/35 = 175, без ошибок. Пройдены encoding, release, lintVitalRelease, подпись v2, ZIP, zipalign и проверка встроенного ключа.
