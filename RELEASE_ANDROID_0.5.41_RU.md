# TVNextR 0.5.41 — Android

Пакет `com.tvnext.app.recovery`, versionCode 541, прежняя подпись. Один release APK: `releases/android/TVNextR-0.5.41.apk`, установка поверх 0.5.40. SHA-256 `d0780bae1743364690dd78f8847a4cdac072e368b07240ad9c75896701aba5f1`. Исходники `846ca4b4ef6320c8e5541a2f5fd4a90ac1b9a0b6`.

TV-гид стал компактнее: колонка каналов расширена с 190 до 216–260dp, названия в одну строку, высота строки уменьшена с 64 до 46dp. Сетка занимает всю оставшуюся высоту. Справа вверху — видео текущего воспроизведения 16:9 с его названием; просмотр других каналов, передач, дат и категорий не переключает этот поток. При обновлении EPG размер видео и положение сетки сохраняются. Начальный фокус запрашивается после размещения сетки; верхние кнопки, категории, переход к сетке и видео доступны с пульта. Переход через полночь и возврат к текущей сетке проверены.

Кнопки Android приведены к общему стилю: угол 4dp, тонкая рамка, прозрачный либо едва заметный фон, явный цветной фокус. Это включает выбор соотношения сторон, настройки, профили, записи, редактор каналов, PIN и резервные копии. Сильно закруглённые пункты заменены; радиус диалогов уменьшен до 8dp. Круглые графические индикаторы и логотипы сохранены.

Исправлено открытие записей. Раньше «Смотреть» запускало файл и закрывало библиотеку, оставляя главное меню без видео. Теперь запись открывается в отдельном полноэкранном плеере с паузой, перемоткой и возвратом в библиотеку. Ошибка остаётся в плеере с кнопкой повтора. Media3 теперь использует DefaultDataSource для локальных файлов и относительных HLS-сегментов; прежние HTTP-параметры IPTV сохранены. При ручной остановке HLS закрывается ENDLIST и доступен как конечная запись.

Во время работы службы записи в правом верхнем углу виден красный REC. Индикатор получает состояние службы, без опроса файлов и без использования устаревших статусов из истории. Остановка, ошибка и завершение снимают его; позднее завершение прежней записи не скрывает новую.

Проверки: 4 TV-guide UI + 96 channels/player UI + 54 native Android API28/35 = 154 без ошибок. Native-сценарий запускает настоящую службу записи с локальным HLS, останавливает её, проверяет REC и ENDLIST, отключает HTTP-источник и читает сохранённые относительные сегменты через реальную фабрику Media3. Проверены TS/HLS с пробелами и кириллицей в пути, пустые файлы, пульт плеера и показ ошибки без возврата в меню. Сборка release, encoding, lintVitalRelease, подпись, ZIP, zipalign и встроенный ключ проверены. Все исходные картинки значка и прямоугольный баннер Android TV, а также PNG внутри APK совпадают с 0.5.40.

Физический телевизор, видеодекодирование реальной записи и запуск этого APK в эмуляторе не проверялись. UI-снимки используют тестовое воспроизведение; снимок с ошибкой специально проверяет доступность повторного запуска и REC.
