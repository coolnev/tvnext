# TVNext Android

[Скачать TVNext.apk](./TVNext.apk?raw=true)

Debug-сборка Android 0.2.0 с исправлениями обновления EPG. Требуется Android 7.0 или новее.

Проверены сборка APK, подпись APK и 201 тест IPTV. Запуск на реальном Android TV ещё не проверен.

Контрольная сумма APK находится в SHA256SUMS. Эта ветка содержит только сборку для скачивания; исходники находятся в рабочей облачной среде.
