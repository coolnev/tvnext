# TVNext Android 0.2.1

[Скачать TVNext-0.2.1-release.apk](./TVNext-0.2.1-release.apk?raw=true)

Android 7.0 и новее; versionCode 3. Оптимизированная release-сборка: отладка отключена, включены R8 и уменьшение ресурсов. Подписана тем же тестовым ключом, что предыдущая APK 0.2.0, для установки обновлением.

Изменения только для Android:
- исправлена классификация ошибок Media3; добавлено восстановление через FFmpeg при сбое декодера и остановке видео со продолжающимся звуком;
- улучшена обработка IPTV HLS/MPEG-TS и HTTP-параметров потока;
- уменьшено обновление списка при изменениях EPG, поиск видимых каналов использует индекс;
- управление архивом скрывается после 3,5 секунды без ввода;
- пауза/старт сохраняются при перемотке и возврате к эфиру, в том числе во время загрузки архивного запроса; отдельные кнопки Play/Pause выполняют соответствующее действие.

Проверки: сборка assembleRelease, 40 тестов Android-плеера на JVM и 25 тестов списка/таймеров, подпись и манифест APK. Прямое скачивание APK проверено по SHA-256; сумма находится в SHA256SUMS.

Запуск на телевизоре TCL и воспроизведение DorcelX/Penthouse Gold не проверены: Android TV недоступен в облачной среде, подключение к серверу провайдера отклонено сетевым прокси. Плавность прокрутки на устройстве также требует проверки.

Ветка содержит APK для скачивания. Исходники изменений находятся в рабочей облачной среде.
