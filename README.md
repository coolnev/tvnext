# TVNext 0.5.24 — управление в оконном режиме

[Скачать APK](https://github.com/coolnev/tvnext/raw/refs/heads/artifacts/release-0.5.24-from-0.5.21-20261029/TVNext-0.5.24-release.apk)

База — оригинальный APK **0.5.21**. Версии 0.2.0 и 0.5.22 не использовались. Исправления внесены непосредственно в байткод 0.5.21.

- В оконной панели доступны пауза/воспроизведение, перемотка, запись, описание, формат и закрытие. Полный ряд кнопок показывается также на каналах без архива и без EPG. В 0.5.23 пауза в эфире и полный ряд на каналах без архива были скрыты исходными условиями интерфейса.
- Панели прогресса и описания занимают всю ширину экрана без боковых отступов.
- OK возвращает фокус на кнопки после смены канала. Панель остаётся открытой до закрытия пользователем.
- Сохраняется одинаковый размер видео при переходах между категориями, каналами и передачами.

Package `com.tvnext.app`, versionCode **38**, Android 7.0/API 24 и новее. Исходный сертификат 0.5.21 сохранён, APK устанавливается обновлением.

Проверки на эмуляторе Android TV API 25: канал без архива и EPG; остановка изображения паузой и возобновление; управление кнопками через D-pad; запись локального HLS с созданием файлов и статусом COMPLETE; прогресс и описание без боковых полей; сохранение геометрии видео; установка обновлением. Физический пульт не проверялся.

Изменены только `classes.dex` и `AndroidManifest.xml`. Остальные 167 файлов исходного APK, включая ресурсы и native-библиотеки, побайтово сохранены.
