# TVNext 0.5.23 — исправления оконного режима

[Скачать APK](https://github.com/coolnev/tvnext/raw/refs/heads/artifacts/release-0.5.23-from-0.5.21-20261029/TVNext-0.5.23-release.apk)

База — оригинальный APK **0.5.21**. Код, ресурсы и библиотеки версий 0.2.0 и 0.5.22 не использовались. Текущие Kotlin-исходники отсутствовали; выполнен точечный патч байткода 0.5.21.

- OK в оконном режиме открывает полную исходную панель управления. В Contour она находится в нижнем управляющем окне.
- Панель остаётся открытой до «Назад» или «Закрыть»; доступны навигация пультом, формат, перемотка, описание и запись.
- Видео сохраняет одинаковый размер при переходах между категориями, каналами и передачами; списки занимают постоянную область до видео.

Package `com.tvnext.app`, versionCode **37**, Android 7.0/API 24 и новее. Сертификат совпадает с 0.5.21, возможна установка обновлением.

Проверены установка обновления с сохранением профиля, панель по OK, переходы фокуса, описание, селектор формата, закрытие и повторное открытие, одинаковая геометрия видео во всех трёх списках. Проверки выполнены на эмуляторе Android TV API 25. Физический пульт и фактическая запись на накопитель не проверялись.

Изменены только `classes.dex` и `AndroidManifest.xml`. Остальные 167 исходных файлов APK, включая ресурсы и native-библиотеки, побайтово сохранены.
