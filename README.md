# TVNext 0.5.26 — управление под видео

[Скачать APK](https://github.com/coolnev/tvnext/raw/refs/heads/artifacts/release-0.5.26-from-0.5.21-20261029/TVNext-0.5.26-release.apk)

В оконном режиме полный ряд управления расположен **непосредственно под видео**, на месте прежних двух кнопок перемотки. Все кнопки помещаются в ширину видеопанели: формат, перемотка назад, пауза/воспроизведение, перемотка вперёд, описание, закрытие и запись; предыдущий канал появляется при наличии истории. OK переводит фокус на управление, стрелки пульта выбирают кнопки.

Нижнее окно на всю ширину экрана содержит прогресс и описание передачи. Кнопки управления в нём не дублируются. Сохранены небольшие боковые отступы текста и постоянный размер видео.

База — оригинальный APK **0.5.21**. Версии 0.2.0 и 0.5.22 не использовались. Использованы исходные элементы управления, callbacks воспроизведения и записи. Изменения выполнены в байткоде; все 167 остальных файлов исходного APK сохранены побайтово.

Package `com.tvnext.app`, versionCode **40**, Android 7.0/API 24 и новее. Исходный сертификат 0.5.21 сохранён.

Проверено на эмуляторе Android TV API25 (1280×720), в оформлении «Классическая» и «Контур»: расположение всех кнопок под видео, отсутствие дублирования в нижнем окне, фокус по OK и навигация D-pad, пауза/resume, завершение записи HLS, описание и меню формата. Размер видео остаётся одинаковым. Физический пульт не проверялся.
