# TVNext 0.5.25 — кнопки оконного плеера

[Скачать APK](https://github.com/coolnev/tvnext/raw/refs/heads/artifacts/release-0.5.25-from-0.5.21-20261029/TVNext-0.5.25-release.apk)

База — оригинальный APK **0.5.21**. Изменения выполнены в его байткоде; версии 0.2.0 и 0.5.22 не использовались.

- В оконном режиме полный ряд кнопок виден сразу в нижнем окне при просмотре каналов. Пауза, воспроизведение, перемотка, запись, описание и формат доступны также без архива и без EPG.
- OK переводит фокус на кнопки. При открытии информационной панели или списка передач состояния больше не блокируют переход к управлению.
- Текст прогресса и описания имеет небольшой боковой отступ **10 dp**. Фон нижней панели по-прежнему занимает всю ширину экрана.
- Размер видео и область списков сохраняются при переходах между категориями, каналами и передачами.

Package `com.tvnext.app`, versionCode **39**, Android 7.0/API 24 и новее. Исходный сертификат 0.5.21 сохранён.

Проверено на эмуляторе Android TV API 25: оформление «Классическая» и «Контур», видимые кнопки до OK, переход фокуса с пульта, пауза и возобновление, завершение записи HLS, открытие описания и боковые отступы. Размер видео одинаков при открытии панелей. Физический пульт не проверялся.

Изменены только `classes.dex` и `AndroidManifest.xml`. Остальные 167 файлов исходного APK сохранены побайтово. Реализация воспроизведения и записи из 0.5.21 сохранена.
