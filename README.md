# TVNext 0.2.2 — навигация Android TV и Windows

[Скачать release APK](./TVNext-0.2.2-release.apk?raw=true)

[Скачать Windows x64 portable](./TVNext-0.2.2-windows-x64-portable.7z?raw=true)

- Стрелки из списка передач принадлежат панели: вправо — к дням, влево из дней — к выбранной дате в программах; влево из программ — к каналам.
- Выбор дня прокручивает программы к этой календарной дате. Первый и последний дни остаются доступными; выход за границы не уводит фокус в видео.
- Повторное открытие списка восстанавливает фактически воспроизводимый канал и его категорию. Строка канала центрируется, в том числе в начале и конце списка.
- Текущая передача центрируется по измеренной координате строки канала.
- При просмотре архива передача выбирается по времени начала архивного потока плюс позиции воспроизведения, а не по текущему времени эфира.
- Панель одинакова для Android и Windows, полноэкранного и обычного режимов.

Проверено: 36 тестов списка и навигации, включая 6 проверок настоящего интерфейса Compose под Xvfb, и 40 тестов Android-плеера. Проверены маршруты клавиш полного экрана и обычного режима, закрытие/открытие архива, физические координаты строк, первая/последняя строки, изменение размера окна, полночь и переходы летнего/зимнего времени.

Android: оптимизированный release APK 0.2.2, versionCode 4, отладка отключена; подпись совпадает с предыдущей 0.2.1 для установки обновлением.

Windows x64: переносной архив 7z со встроенной Java 21, libmpv и загрузчиком Vulkan. Распакуйте целиком и запустите TVNext/TVNext.cmd. Для распаковки подойдёт 7-Zip или совместимый архиватор. Установка Java не требуется.

Проверки интерфейса выполнены на Linux со стандартным JVM/Compose-рендерингом. Запуск на физическом TCL и Windows-компьютере в этой среде недоступен; это ограничение проверки, а не гарантия работы на любом устройстве.

Контрольные суммы находятся в SHA256SUMS. Ветка для скачивания содержит сборки, исходники остаются в облачной рабочей среде.
