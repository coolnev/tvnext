TVNext 1.0.24 — Windows x64, портативная версия

Распакуйте ВЕСЬ архив в отдельную папку с правом записи, затем запустите TVNext.exe.
TVNext.cmd — дополнительный вариант запуска.
Java и видеодвижок уже включены. Устанавливать VLC, Java или наборы кодеков не нужно.
Windows 10/11 x64; аппаратное декодирование зависит от видеокарты и её драйвера.

Настройки, профили, EPG и записи находятся в папке data рядом с программой.
Прежняя установленная версия и её данные не затрагиваются.
Для обновления распакуйте новую версию поверх старой, сохранив свою папку data.
Не запускайте две копии из одной папки одновременно.

Панель вверху: «Главная», «Каналы», «ТВ-гид», «Медиатека», «Поиск», «Настройки».
Меню «•••»: записи, редактор каналов, профили. «Главная» доступна мышью с любого экрана;
в полноэкранном просмотре наведите мышь, чтобы показать панель.

Мышь: один щелчок по видео — пауза/продолжение, двойной — полный экран.
Колёсико над видео меняет громкость; над списком прокручивает список.
Нижние кнопки имеют подсказки при наведении. Ползунки перемотки и громкости
работают щелчком и перетаскиванием. В списке передач один щелчок выбирает описание,
двойной запускает эфир/архив; можно нажать кнопку «Смотреть» или Enter.

Клавиатура: пробел или K — пауза/продолжение; M — выключить/включить звук;
F11 или Alt+Enter — полный экран; Esc — вернуться к оконному просмотру, затем в меню.
J/L — назад/вперёд на 10 секунд; стрелки влево/вправо над видео — так же,
Ctrl+стрелки — на минуту. Стрелки вверх/вниз над видео и +/- меняют громкость.
PageUp/PageDown — предыдущий/следующий канал; I — информация о потоке;
B — список/видео; Alt+Home — главная. В списках стрелки перемещают фокус,
Enter выбирает элемент. При вводе текста пробел и буквы остаются вводом текста.

«Мои записи» и редактор каналов — на главном экране. Запланированные записи
выполняются, пока TVNext работает; после закрытия программы запись не идёт.
Во время записи виден красный REC. Повторная кнопка записи на этом канале
останавливает её. Запись можно остановить и удалить через «Мои записи».

Автофреймрейт по умолчанию выключен. В настройках видны режимы, сообщённые
Windows-драйвером. Изменения временные: исходный режим восстанавливается при
выходе из просмотра/программы. Частота кадров видео и герцы монитора различаются.
Windows EnumDisplaySettings сообщает целые герцы: дробные режимы, которые драйвер
не отдаёт точно, не выдаются за 23,976/59,94 и не выбираются по догадке.

Если окно не открылось, запустите TVNext-debug.cmd; журнал — data/startup.log.
В журнале могут быть адреса ваших источников: не публикуйте его целиком.
