# TVNext 1.0.25 r3 — Windows portable x64

Исправлено перевёрнутое изображение в режимах «Аппаратный — GPU» и «Авто», когда используется GPU-вывод. В r2 кадр libmpv не учитывал нижнее начало координат OpenGL-поверхности Skia. Теперь render API задаёт вертикальное преобразование при рендеринге FBO; дополнительного копирования кадра в память процессора нет.

Кнопка предыдущего просмотренного канала получила изогнутую стрелку возврата вместо значка предыдущей дорожки. Назначение и подсказка кнопки сохранены.

Ошибка r2 воспроизведена нативным Windows libmpv/ANGLE на видео с разными цветами четырёх углов и подписями TOP/BOTTOM: вместо красного верхнего левого угла обнаружен синий, надписи перевёрнуты. После исправления проверяется расположение всех четырёх углов, в том числе после пересоздания render context. Изображения и журналы — в `releases/windows/validation-1.0.25-r3/`. Нативная проверка проходит под Wine; полноценный физический Windows GPU/HDMI здесь недоступен.

Версия приложения **1.0.25** сохранена; r3 — ревизия Windows-архива. Android и его APK не менялись.

[Скачать портативный ZIP r3](https://github.com/coolnev/tvnext/releases/download/windows-v1.0.25-r3/TVNext-1.0.25-windows-x64-portable-r3.zip). Распакуйте весь архив и перенесите свою папку `data` из прежней сборки.
