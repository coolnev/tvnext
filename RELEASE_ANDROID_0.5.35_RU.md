# TVNextR 0.5.35 — компактный оконный режим

В оконном списке передач убрана дата перед названием: остаются время и название. В той же области помещается вдвое больше строк — в проверке 400×600 точек 14 вместо 7. Список сохраняет фокус после загрузки EPG и позволяет переходить через полночь.

Под видео расположена компактная полоса управления: уменьшены кнопки, интервалы, шкала и подписи времени. «Запись» находится в одной строке с перемоткой. Доступны формат, предыдущий канал, перемотка, запись эфира, а при архиве — пауза и LIVE. Размер видео определяется прежней фиксированной областью.

Вместо блока следующих передач постоянно отображается описание выбранной передачи или фильма. При просмотре списка описание меняется вместе с выделенной передачей, без запуска воспроизведения. Используется сюжет из EPG, а при его отсутствии — найденные метаданные. Постер/кадр и текст подстраиваются под оставшуюся высоту; длинный текст прокручивается внутри панели. Отдельная кнопка «Описание» убрана из оконного режима. Предоставленный ключ Кинопоиска включён в APK.

Проверки: 66 channels/UI без ошибок. Подтверждены удвоенная плотность без даты, фокус после асинхронной загрузки, навигация между сутками, переход к видео и fullscreen, компактная запись в одной строке на ширине 240 точек, сохранение фокуса при появлении архивных кнопок, одиночный шаг перемотки 60 секунд. Проверено появление сюжета после декодированного постера в панели 240×170 точек. Проходят checkEncoding, release, lintVitalRelease, ZIP integrity, подпись v2 и zipalign.

Именно release APK установлен поверх 0.5.34 в Android 9 эмуляторе. На синтетическом EPG описание видно под видео, кнопки «Описание» и прежнего блока следующих передач нет, запись остаётся в строке управления. В оконном списке видны 14 строк без даты; UP без OK меняет описание на «Передача -01» при сохранённой области видео. Установленный файл совпадает по SHA-256 с публикуемым. FATAL/ANR приложения не зафиксированы.

Ограничения: физический ТВ и настоящее видео не проверялись; тестовый поток недоступен. Программный эмулятор работает без KVM, System UI при загрузке ОС потребовал продолжения после ANR. Живые Kinopoisk/TMDB API блокируются сетью среды; проверка появления описания из API использует контролируемые ответы и декодированную картинку.
