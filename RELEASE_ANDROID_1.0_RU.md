## Интерфейс

Текущий канал/фильм и видео на главной объединены в один фокусируемый блок. Общая рамка охватывает текст и видео, OK открывает полный экран; нажать можно на любую часть. Дублирующей подписи под видео нет. Отдельная лента «Сейчас идёт» удалена. На узких экранах название сохраняет место за счёт компактной сводки; фон общей кнопки не затемняет видео.

Сообщение «Еще раз нажмите Назад…» использует пассивную текстовую подсказку внутри приложения, без значка Android и без смены фокуса. Внизу главной, в информации о приложении и общем интерфейсе — версия 1.0. Общий Desktop-код тоже переведён на 1.0, параметр установщика — 1.0.0; новый Windows-установщик не собирался.

Оформление → Язык интерфейса: Русский / English / 中文（简体）. Язык сохраняется; переведены меню, кнопки и подсказки. Пользовательские названия, EPG и описания провайдера не переводятся. Убраны дублирующий «Акцентный цвет», «Запускать на весь экран» из общих настроек Android и «Мои записи» из обслуживания. Записи остаются на главной.

Часы увеличены на 30%. В режиме без фона чёрные цифры смещены на 2dp вниз и вправо под белыми цифрами, без размытия. С фоном тени нет. Отступы названия канала и REC скорректированы под больший размер.

## Записи

Кнопка записи останавливает уже записываемый канал, включая запись по расписанию. Для новых расписаний сохраняется ID канала; прежние записи поддерживают сравнение URL. Другой записываемый канал не заменяется молча. Повторные запросы во время запуска/остановки не создают лишних записей, «Запись начата» показывается после фактического запуска службы.

В библиотеке у активной записи есть «Остановить». Удаление активной записи подтверждается кнопкой «Остановить и удалить», ждёт завершения службы и затем удаляет файлы. Остановка адресована конкретному ID, чтобы не остановить более новую запись. Оставшийся после сбоя флаг recording не блокирует удаление, если служба уже не пишет. recording/partial/complete показываются как понятные статусы на выбранном языке.

Остановка по общему лимиту TVNext, нехватка свободного места, отключённый накопитель, ошибка записи файла и сеть различаются. Проверка места оставляет 16МиБ для завершения HLS/метаданных, выполняется на IO примерно раз на МиБ. При лимите сохраняются уже готовые HLS-сегменты и конечный индекс. Ошибка финализации не подменяет первоначальную причину. Исходные URL и тексты системных исключений не сохраняются в библиотеке. Для старых обобщённых ошибок точную причину восстановить нельзя.
