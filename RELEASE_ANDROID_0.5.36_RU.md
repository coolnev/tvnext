# TVNextR 0.5.36 — дозагрузка описаний и поведение резервного EPG

Пользовательский JSON «Один дома 2» корректно читается: поддерживаются description и shortDescription. На нём воспроизведены две ошибки: карточка, прерванная после постера, блокировала дозагрузку сюжета своим частичным кэшем; короткое название нумерованного продолжения не совпадало с полным названием с подзаголовком после двоеточия.

Незавершённая карточка теперь возобновляется сразу. Сохраняется уже найденный ID фильма и картинка, полная карточка запрашивается без нового поиска. Если открытая карточка осталась только с постером, доступны два ограниченных повтора дозагрузки сюжета. Дополнительные кадры запрашиваются после получения сюжета. При поиске нумерованной части допускается опущенный подзаголовок после двоеточия; полное совпадение приоритетно, номер части сохраняется.

При готовом кэше переход на канал без EPG не запускает скачивание ещё не загруженных резервных файлов. Резервы дополняют программу при первом импорте, обновлении основного источника и ручном принудительном обновлении; уже загруженные резервные данные читаются сразу и обновляются самостоятельно, когда их программа заканчивается. Полнота программы зависит от источников.

«Докачка» означает реальное продолжение сохранённого файла. При нуле байт показывается подключение или повтор подключения; небольшие объёмы отображаются в байтах/КБ. Тайм-аут подключения — 10 секунд, ожидания данных — 15 секунд. Две ошибки без полученных байтов завершают попытку, для файла с сохранёнными данными остаются до четырёх попыток. Сохранённая программа остаётся доступной.

Проверки: 216 IPTV, 32 metadata, 66 channels/UI и 26 Android native API 28/35 — 340 без ошибок. Три проверки пользовательского примера до исправления: чтение полей прошло, два сценария поиска/частичного кэша упали; после исправления проходят. Проверены дозагрузка сюжета в открытой карточке без повторного поиска, отсутствие фонового HTTP для пустого канала при готовом кэше, подписи прогресса, два отказа без байтов и прежнее HTTP Range-восстановление. Release, lintVitalRelease, кодировка, подпись v2, zipalign и ZIP integrity проходят. Ключ Кинопоиска сохранён в APK.

Живые API и основной сервер EPG блокирует сеть среды; ответы на телевизоре не проверены. Для проверки использованы пользовательский JSON, контролируемые HTTP-ответы, Compose и Android native SQLite. Физический ТВ не использовался.
