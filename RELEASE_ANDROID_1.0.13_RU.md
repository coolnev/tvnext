# TVNext 1.0.13 — Android

Для старых аппаратных видеодекодеров Amlogic добавлена асинхронная подача буферов MediaCodec: отдельные потоки обслуживают очередь и уведомления о готовых кадрах. Это рекомендованный Google вариант для устройств с пропусками кадров на Android 6–11; штатный Ugoos X3 на S905X3 использует Android 9.

Оптимизация применяется автоматически по реальному имени аппаратного видеодекодера `OMX.amlogic.*` / `c2.amlogic.*` на API 23–30, независимо от AFR. При отказе запуска async повторяется инициализация того же аппаратного кодека в синхронном режиме; повторные async-попытки для этого имени не выполняются до пересоздания плеера. В диагностике вывода виден фактически запущенный режим `Amlogic async` или `Amlogic sync fallback`.

Сохраняются исходные параметры 4K/частоты кадров, SurfaceView, настройки AFR и разрешение Android. Аудио, программное видео, другие производители и новый Android используют штатную Media3-политику. Dolby-декодер и PNG/баннер Android TV совпадают с 1.0.12.

**242 проверки прошли**: 80 Player и 162 Android API 28/35, включая 12 новых проверок Amlogic. Проверены передача UHD Configuration, сохранение аппаратного кодека при отказе async, ограниченность повторов, ошибки, выбор фабрики и все режимы звука. Release, lintVitalRelease, encoding, Desktop compileKotlin, подпись, ZIP и zipalign 16 KiB прошли.

На физическом Ugoos X3 APK не запускался: здесь проверена интеграция, а не работа прошивки Amlogic или измеренный FPS. Конкретный проблемный 4K-поток недоступен. Полное устранение рывков на приставке пока не подтверждено. Windows-установщик не собирался.
