# Android: медиатека

Дополнение к предыдущим Android-исправлениям каналов, ТВ-гида, архива и настроек.
Windows использует прежний MediaScreen; новый экран вызывается только на Android.

- Вход в медиатеку открывает сетку категорий, фокус на «Все».
- OK на категории открывает сетку крупных вертикальных постеров (высота карточки 280 dp).
- При возврате из просмотра сохраняются категория и позиция выбранного фильма.
- Во время воспроизведения: вверх +1 минута, вниз −1 минута; удержание повторяет перемотку.
- OK / Enter: пауза или продолжение. Вверх/вниз больше не переключают фильмы.
- Влево: фильмы текущей категории; ещё влево: категории. В сетке фильмов для движения используются вправо, вверх и вниз; влево зарезервировано для возврата.
- Вправо: полное описание TMDB. Ещё вправо или Назад закрывает описание.
- Описание прокручивается автоматически спустя 3 секунды, если не помещается.
- Назад: описание → видео → фильмы → категории → главный экран.
- Сохранены выбор источника, обновление, избранное (удержание OK на постере) и возврат к текущему просмотру.
- После перемотки отображается позиция, при остановке — статус «Пауза».

Проверка: проверены структура изменённых Kotlin-файлов, целостность ZIP и неизменность desktop-файлов.
Сборка :apps:android:assembleDebug не выполнена: загрузка Gradle 9.4.1 завершилась Network is unreachable.
Проверка на Android-устройстве/эмуляторе в этой среде недоступна. ZIP содержит исходники, не APK.
