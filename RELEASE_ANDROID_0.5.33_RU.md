# TVNextR 0.5.33 — сохранённый EPG и завершение импорта

Сохранённый EPG читается с диска при запуске. Переименование, перестановка и смена категории канала не сбрасывают скачанный источник. Проверка свежести учитывает наличие текущей и будущей программы: после суток пригодный гид сохраняется до исчерпания покрытия, максимум семь дней. Истёкшая программа обновляется; ручное обновление доступно.

При фоновом обновлении открытый список передач остаётся на экране до готовности новых данных. Полный сохранённый гид не публикует промежуточные версии импорта. Это убирает подмену списка одной строкой, скачки выбора и отмену запроса описания выбранного фильма.

Счётчик EPG учитывает объединение каналов источников. Воспроизведён случай 1533 + 267: все 1800 доступны, счётчик показывает 1800. Источник может не содержать программу всех каналов плейлиста; отсутствующая программа не выдумывается.

Вместо одного индикатора показываются скачанные МБ, обработанные передачи и этап сохранения архива. Архив переносится по каналам, активная версия переключается после сохранения, старые строки удаляются отдельно порциями. Введён общий предел обработки источника 20 минут. Ошибка завершает индикатор и сохраняет предыдущую программу. Неудачные/неподходящие источники имеют сохранённую паузу перед повтором.

Описание фильма дозагружается из полной карточки и после постера. Временная ошибка полной карточки Кинопоиска повторяется ограниченно. Заглушки с переносами, неразрывными пробелами, HTML и одиночным названием жанра не перекрывают найденный сюжет. Проверено появление описания с уже декодированной картинкой в оконном подробном описании и обеих компоновках полноэкранного гида.

Проверки: 213 IPTV, 27 metadata, 59 channels/UI, 24 Android native — 323 без ошибок. Native SQLite API 28/35: импорт 86 400 передач для 1800 каналов, обновление с сохранением 45 000 записей, включая архив. Проверены зависший запрос, обрыв, сохранение кэша и очистка без удаления более новой загрузки. Release, lintVital, кодировка, ZIP, подпись и zipalign проходят.

Release APK установлен поверх 0.5.32 в Android 9 эмуляторе. Программа из кэша возрастом 37 часов доступна, за два запуска нет HTTP-запроса EPG. Список передач и настройки открываются. Подпись прежняя; сбрасывать данные приложения не требуется. APK и полный исходный код сохранены на GitHub, исходный пользовательский ZIP сохранён отдельно в source-archives.

Ограничения проверки: живые Kinopoisk/TMDB API блокирует сеть окружения; работа с реальным ключом телевизора не подтверждена. Доступность описаний проверена управляемыми ответами API и интерфейсом с картинками. Эмулятор работает без KVM; System UI при холодной загрузке ОС показал ANR до старта приложения. Проверка не измеряет плавность видео на физическом ТВ.
