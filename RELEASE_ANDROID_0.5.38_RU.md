# TVNextR 0.5.38 — Android

Пакет `com.tvnext.app.recovery`, versionCode 538, прежняя подпись. Установка поверх 0.5.37 с сохранением EPG и настроек. APK: `releases/android/TVNextR-0.5.38.apk`; SHA-256 `9bb698f88d564fa9d1d0e197f265f08a447ab24125a42ab595b8a8add601c0f4`. Исходники: `716b9090ffb68d54ed8de960a774cc56af0015a1`.

TV Guide: курсор передаёт абсолютное время вместо повторного прибавления дней по ещё не обновлённой сетке. Запросы привязаны к поколению; запоздавший ответ, включая репозиторий, игнорирующий отмену, не может заменить более новую сетку. Быстрый возврат к ещё отображаемому дню отменяет ожидающий запрос другого дня. Перечитываются видимые строки, играющий канал и первые восемь строк; уже прочитанные передачи того же дня сохраняются при временно пустом ответе. Повторный вход открывает день реально играющего LIVE/архива. Навигация по дням использует локальный кэш без загрузки XMLTV.

Описания: картинка, текст рядом с ней и продолжение под ней прокручиваются одним блоком. Ровные расстояния между строками сохранены. Подтверждено одинаковое смещение всех трёх частей для постера/кадра, обычного и компактного описания.

Нижняя панель: надпись LIVE рядом с названием канала убрана; в архиве остаётся «Архив».

Кинопоиск переключён на отдельный сервис `kinopoiskapiunofficial.tech`. Прежний dev-провайдер отключён. Используются поиск v2.1 `films/search-by-keyword` с `keyword`, карточка v2.2 `films/{id}`, кадры `films/{id}/images?type=STILL`. Обрабатываются `films`/`items`, `filmId`/`kinopoiskId`, `nameRu`/`nameEn`/`nameOriginal`, строковые URL постеров и `items` кадров. Новый ключ пользователя включён в APK через локальный build input; значения в текстах GitHub нет. Новый namespace `settings.kinopoisk_unofficial_key` не позволяет прежнему ключу dev перекрывать новый default после обновления.

В настройках есть «Проверить Кинопоиск»: авторизованный запрос к активному сервису с пределом 5 секунд. Результат различает успех, отсутствие/отклонение ключа, лимит, ошибку сервера, некорректный ответ и отсутствие связи. Повторный клик во время проверки не создаёт новый запрос; уход из настроек отменяет проверку. Ключ в диагностике не выводится.

Проверки: 39 metadata + 2 TV Guide UI + 78 channels/UI + 44 native Android = 163 без ошибок. Native проверки API 28/35 включают поздний ответ старого дня, пустой архив, возврат к текущему дню, повторный вход и реальную дату архивного воспроизведения. Пройдены release, encoding, lintVitalRelease, подпись v2, ZIP, zipalign и наличие нового ключа в DEX.

Физический ТВ, реальный IPTV-поток и запуск этого APK в эмуляторе не проверялись. Живые API Kinopoisk/TMDB закрыты сетевой политикой среды; новый ключ на живом сервере не подтверждён. Проверен контракт отдельного сервиса на контролируемых ответах, включая описания, постеры, кадры и ошибки соединения.
