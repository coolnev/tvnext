# TVNext 1.0.24 — Windows portable x64

Версия сохранена: **1.0.24**. Windows 10/11 x64. Распаковать весь ZIP в папку с правом записи и запустить **TVNext.exe**. Java, libmpv и необходимые DLL включены; установки VLC/Java не требуется. Настройки, EPG, профили и записи находятся в соседней папке `data`.

Общие с Android экраны: главное меню с единым блоком текущего канала и видео, оконный просмотр с постоянным размером видео, плотный список передач без повторной даты, компактный ТВ-гид, нижняя панель с текущей/следующей передачей, описание, медиатека и плоские кнопки. Управление мышью и клавиатурой: стрелки/Enter, Esc назад, F11 полноэкранное окно, I сведения о потоке, L переключение списка/видео.

Перенесены индексированный EPG с сохранением между запусками и ограничением хранения, подбор описаний фильмов/сериалов TMDB и Кинопоиска, отдельные переключатели/проверка источников, RU/EN/ZH, родительский PIN, профили, редактор каналов, запись/планирование/воспроизведение записей и REC. Прямой эфир и архив используют общую с Android логику перемотки по времени. Ключ Кинопоиска включён в бинарную сборку из приватного свойства Gradle; в новых исходных файлах ключа нет.

Windows-движок — libmpv. Исправлены ABI событий, порядок инициализации, pause/resume, работа с локальными файлами, отсечение устаревших кадров при переключении, источниковая частота кадров и состояние буферизации. Переиспользуется буфер вывода, исключено лишнее программное увеличение HD до 4K. Режим аппаратного декодирования зависит от драйвера; интерфейс показывает фактический режим. Текущий вывод кадров проходит через память и Compose; полноценный нативный HDR-вывод и производительность 4K на конкретной видеокарте здесь не подтверждены.

Автофреймрейт по умолчанию выключен. Используются режимы текущего монитора Windows с временным переключением и восстановлением. EnumDisplaySettings сообщает целые герцы: дробные частоты не выдумываются. Запланированные записи выполняются только при работающем TVNext.

## Проверка

Успешны 543 общих/JVM проверки проигрывателя, IPTV, описаний, каналов, главного экрана, медиатеки, настроек, ТВ-гида и Desktop; 242 Android-проверки после общих изменений; 3 проверки БД. Дополнительно реальный DesktopEpgRepository с SQLite и HTTP-счётчиком: импорт, повторное открытие без HTTP, отсутствие второго XML-кэша.

На Windows JRE и DLL из архива через Wine 10 реально декодированы AVC/AAC 25 fps и HEVC Main10/AC3 23,976 fps; проверены четыре переключения, пауза с неподвижной позицией, продолжение, перемотка, остановка и освобождение плеера. Вывод звука в этой среде заменён null-устройством, поэтому слышимость/HDMI не проверены. Скриншоты общих компонентов и запуск полного Desktop-интерфейса проверялись на Linux/Xvfb. Полное окно Windows под Wine ограничено отсутствием штатного набора Windows-шрифтов. Физического Windows-ПК, GPU/HDMI и живых закрытых потоков провайдера в среде нет.

## Воспроизводимая упаковка

JDK 21, Gradle 9.4.1, Android SDK 36 для конфигурации проекта; 7-Zip и LLVM (`clang`, `lld-link`, `llvm-dlltool`, `llvm-rc`).

```sh
python3 tools/prepare_windows_runtime.py --sevenzip /path/to/7z
python3 tools/build_windows_launcher.py --llvm-bin /path/to/llvm/bin
gradle :apps:desktop:windowsPortableZip -PdesktopTarget=windows
```

Результат: `apps/desktop/build/distributions/TVNext-1.0.24-windows-x64-portable.zip`. Внешние зависимости закреплены URL и SHA-256; оригинальные лицензии Java сохранены, сведения о сторонних библиотеках находятся в `licenses` и `RUNTIME-SOURCES.json`.

Windows-исходники отмечены тегом `windows-v1.0.24`. Android APK и тег `v1.0.24` не заменяются.
