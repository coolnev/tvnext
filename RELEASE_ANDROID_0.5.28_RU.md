# TVNextR 0.5.28 — управление и непрерывный EPG

База: предоставленный пользователем `TVnextR-source.zip`. Исходный ZIP сохранён без изменений в `source-archives/TVnextR-source-2026-11-05.zip`; его копия на GitHub скачана обратно и проверена по SHA-256.

- Передачи всех доступных суток находятся в одном хронологическом списке. Вверх/вниз переходят через полночь; колонка дат следует за выбранной передачей. Выбор даты остаётся быстрым переходом, не отсекает остальные сутки.
- При просмотре архива открытие списка восстанавливает передачу по времени воспроизведения и отдаёт ей фокус. Промежуточные данные текущего эфира при загрузке EPG не заменяют архивный выбор.
- В оконном режиме вправо со строки канала открывает его программу; следующее отдельное нажатие выбирает видео. OK на видео открывает полный экран после отпускания кнопки. Удержание вправо не пропускает промежуточную панель.
- Небольшие часы находятся рядом с названием канала внутри одной строки; отдельная кнопка часов на Android удалена.
- Видео имеет постоянную область при переключении категорий, каналов и программы. Панель управления и EPG прокручиваются ниже. Кнопки управления переносятся по ширине и не перехватывают начальный фокус.

APK: `releases/android/TVNextR-0.5.28.apk`. Это release-вариант предоставленной Recovery-ветки: пакет `com.tvnext.app.recovery`, версия `0.5.28-recovery-preview`, код `528`, `debuggable=false`. Подпись сохраняет конфигурацию исходников (Android debug certificate); пакет устанавливается отдельно от `com.tvnext.app`.

Проверено: `checkEncoding`, 48 тестов без ошибок и пропусков, сборка `assembleRelease` с `lintVitalRelease`, подпись APK v2, выравнивание ZIP и целостность APK. Пять тестов Compose исполняют реальные циклы клавиш пульта, включая переходы через сутки, позднее поступление EPG, возврат в архив, выбор видео и управление в узкой области. Сводка — `releases/android/validation.json`, SHA-256 — `releases/android/SHA256SUMS`.

Проверка на физическом Android TV не выполнялась.
