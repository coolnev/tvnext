# TVNextR 0.5.37 — Android

Пакет `com.tvnext.app.recovery`, versionCode 537. Прежняя подпись, установка поверх 0.5.36. APK: `releases/android/TVNextR-0.5.37.apk`, SHA-256 `12e41ca2e2b8f0081860107971f3552ce7be0b480d9ed3a65fccf199eddec81f`. Исходники: `f2e6e9abe38dc5a86c688f6027dd7591fac83e27`.

Исправлен TV Guide по долгому OK: состояние фокуса, задания и индексы создаются до запуска первой корутины. Немедленный ответ локального кэша больше не вызывает обращение к неинициализированным полям и отмену scope. При повторном открытии гид перечитывает каналы из локальной базы, проверяет сохранённую категорию и выбирает категорию играющего канала. Каналы публикуются до запросов EPG: отсутствие/ошибка программы не означает пустую категорию. Повторный вход и смена категории не запускают загрузку XMLTV.

PIN: удалена нарисованная клавиатура; оставлено небольшое поле с системной цифровой клавиатурой Android и действием «Готово». Общее наблюдаемое состояние доступа сразу убирает красные названия и замки после правильного PIN. Разблокировка хранится в памяти до завершения приложения, PIN по-прежнему хранится как salted SHA-256.

В оконном списке убрана подпись «Программа передач», сохранено название канала. Ёмкость рассчитывается по доступной высоте и шагу строки 33dp; заполняются все полные строки без фиктивных пустых мест у начала и конца EPG. Например, в области 400×600dp помещается 16 строк вместо 14. Стабильный хост фокуса и навигация через полночь сохранены.

Текст рядом с изображением занимает целое число строк с округлением вверх; убран дополнительный отступ перед продолжением под изображением. Проверены равные расстояния между базовыми линиями для кадра/постера, обычного и компактного описания.

Нижняя панель: название канала белое, 20sp/SemiBold, крупнее названия передачи. Полоса прогресса расположена непосредственно под каналом, до времени и названия передачи; дублирующая полоса в кнопках скрыта. Обычная полоса для канала без архива и отметка LIVE в архиве сохранены.

Проверки: 78 channels/UI + 34 Android native = 112, без ошибок. Native проверки выполнялись на API 28 и 35. Пройдены encoding, release, lintVitalRelease, подпись, ZIP и выравнивание. Встроенный ключ Кинопоиска сохранён; значения ключа в исходниках GitHub нет. Результаты и снимки рядом с APK.

Release APK установлен поверх 0.5.35 в Android 9 эмуляторе. Подтверждены 16 строк оконного списка без подзаголовка и даты перед передачей, переходы вправо к программе и видео, затем OK в fullscreen. В нижней панели видны увеличенное имя канала и новая последовательность элементов. Сценарии долгого OK до TV Guide и системной клавиатуры PIN в эмуляторе не завершены: UIAutomator возвращал null root, затем сессия завершилась. Логика гида и PIN прошла отдельные native Android регрессии на API 28/35.

Физический телевизор и реальный IPTV-поток не проверялись. Программный Android 9 эмулятор работает без KVM; его скорость не характеризует телевизор. Живые Kinopoisk/TMDB API ограничены сетью среды; механизм поиска этой сборкой не изменялся.
