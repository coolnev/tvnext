# TVNext: этап 13 — экран каналов, дни EPG, метаданные

Исходная база: этап 12. Эталон поведения: оригинальная Android 0.5.21; версии 0.5.22+ не использовались. Windows не переделывалась.

## Что изменено

- Полноэкранный список каналов на Android переработан в три колонки с относительными ширинами: каналы, программы, дни. При настройке «Описание снизу» область списка занимает 100% ширины, нижняя информационная панель — тоже. Стандартная полноэкранная плавающая панель не перекрывает этот гид.
- При выборе канала без OK загружается его EPG без смены воспроизводимого канала. Текущая программа этого канала выводится на той же стартовой высоте списка, что и выделенный канал. Даты берутся из действительного диапазона EPG, доступны фокусом и OK. При переводе фокуса на дату список программ фильтруется на этот день. Добавлены сокращения дней недели.
- Исправлено перехватывание стрелки RIGHT, которое прежде скрывало список вместо перехода по колонкам. Сохранён вход в категории слева из строки канала.
- Изображение внизу: кадр (TMDB backdrop) → постер (TMDB poster), при необходимости запасные изображения Kinopoisk.dev. Загрузка через существующий кеширующий загрузчик логотипов; если изображения нет или загрузка не удалась, пустая область не создаётся.
- При отсутствии XMLTV-описания используется описание метаданных. Поиск запускается с задержкой 280 мс после фокуса и отменяется при переходе к другой передаче. Кеш результатов — до 256 заголовков в текущем процессе. Нормализация названий, проверка точного совпадения, тайм-ауты запросов.
- «Настройки → Оформление → Описание передач» теперь реально переключают «Снизу во всю ширину» и «Справа», значение хранится в SettingsRepository.
- «Настройки → Медиатека»: поле для личного ключа Kinopoisk.dev и проверка связи. Резерв не используется без введённого ключа. API: api.poiskkino.dev/v1.5, заголовок X-API-KEY, только HTTPS. Ключ в исходники не включён и в логи не выводится.
- Desktop и ветки релизов после 0.5.21 не использованы, AppId восстановительной сборки сохранён.

## Реальные ограничения

- Полная Gradle/AGP-компиляция и тест на Android TV не выполнены в этом окружении (Android SDK/Gradle недоступны). Требуется одна итоговая сборка у агента.
- Надёжность запросов TMDB/Kinopoisk и доступность кадров на конкретных каналах можно подтвердить только с доступными API и сетью телевизора; гарантировать наличие метаданных для каждой передачи нельзя. Ключ Kinopoisk вводит владелец вручную.
- Новая сетка предназначена прежде всего для полноэкранного просмотра с раскрытым списком. Оконный режим сохраняет прежнее поведение этапа 12.
- Для правого описания выделено 20% ширины, как отдельная компоновка с текстом и изображением. Сверка пикселей с оригинальной 0.5.21 требует скриншотов с TCL после установки.

## Одна проверка у агента

`gradle :apps:android:assembleRelease --stacktrace --console=plain`

После запуска: открыть список слева; пройти канал → передача → дата стрелками; выбрать другой день; проверить смену программы без переключения канала; проверить нижний режим во всю ширину; переключить описание справа и назад; проверить отсутствие пустого квадрата без картинки; открыть ввод и проверку ключа Kinopoisk.dev.
