# TVNext — этап 22: управление пультом, таймер инфопанели, автопрокрутка

Основа: полный проект этапа 21. Android TV.

## Управление каналами в полноэкранном режиме
- Короткое OK: показать нижние кнопки и передать фокус на паузу для архива или первую доступную кнопку для LIVE.
- Длинное OK: открыть ТВ-гид (сохранено).
- В нижней панели: влево/вправо — перемещение между кнопками, OK — выполнение, вверх или Back — закрыть.
- Back при закрытых слоях: перейти из полноэкранного просмотра в оконный. В оконном режиме выбор текущего канала/видео и OK возвращает на весь экран.
- Вверх/вниз без открытых кнопок в архиве — перемотка с шагом из настроек.
- Первое вправо: пассивная нижняя информационная панель; скрывается по параметру «Информация о передаче»: N секунд / 0 постоянно / выкл.
- Второе отдельное нажатие вправо: подробное описание с изображением, без автоскрытия. Повторы KeyDown при удержании вправо не считаются вторым нажатием.

## Медиатека
- Короткое OK открывает транспортные кнопки вместо немедленной паузы. Back скрывает кнопки.
- Первое вправо: временная нижняя панель на срок параметра информации о передаче. Второе вправо: постоянная карточка информации о фильме.
- Действия кнопок навигацией влево/вправо, OK для активации; вверх закрывает активную панель.

## Описания
- AutoScrollText в Android и Desktop: только если текст не помещается, после 3 с ожидания медленно прокрутить к концу, 3 с пауза, обратно, 3 с пауза; повтор.
- Подробности телепрограммы теперь используют AutoScrollText, а не неограниченный Text.
- Обычные элементы Desktop, плеер, native/NDK/Gradle не изменялись; Desktop получает только дополнительный неиспользуемый аргумент интерфейса MediaScreen ради совместимости expect/actual.

## Проверки, необходимые агенту
1. Выполнить `:apps:android:assembleRelease` (или compileReleaseKotlinAndroid). В этой среде полная Android-сборка не выполнена.
2. Полный экран LIVE: OK открывает кнопки; стрелки выбирают кнопки; Back закрывает кнопки; ещё один Back показывает оконный режим.
3. Архив: вверх/вниз перематывает при скрытых кнопках; OK открывает кнопки; кнопка паузы срабатывает за одно OK.
4. Вправо один раз: панель исчезает через выбранные 3/5/... секунд; 0 — постоянно; выключено — не показывать. Дважды вправо — описание остаётся до Back.
5. Длинное OK по-прежнему ТВ-гид. Навигация и выбор канала в широком списке не изменены.
6. Длинное описание: 3 секунды вверху, плавно до низа, 3 секунды, обратно, повтор. Короткое описание неподвижно.
7. Медиатека: аналогичные OK/вправо/Back.

ВНИМАНИЕ: Это исходники для агента; без запуска на телевизоре нельзя гарантировать навигацию фокуса/отсутствие регрессий.
