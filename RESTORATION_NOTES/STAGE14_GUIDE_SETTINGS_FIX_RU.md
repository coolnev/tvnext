# TVNext — этап 14: настройки и список каналов

Основа: загруженный пользователем архив `TVnextR-source(1).zip`, который агент ранее успешно компилировал. Изменены только Android-настройки и общий Android-режим гида. Windows, Gradle, Native/FFmpeg и хранение данных не тронуты.

## Исправлено

1. В `AndroidReferenceSettingsScreen.kt` исправлено ошибочное приведение `this as BoxWithConstraintsScope` внутри `ColumnScope`. При открытии настроек оно приводило к `ClassCastException`. Ширина колонки теперь вычисляется на уровне `BoxWithConstraints` до вложенного `Column`.
2. В `AndroidWideGuide.kt` восстановлены название текущей передачи, начало и конец и тонкая шкала прогресса прямо под названием каждого канала. Для данных используется существующий `ChannelsComponent.nowPlaying` (XMLTV/EPG), с резервом из уже загруженной временной шкалы выбранного канала. Никакие названия программ не выдумываются.
3. Строка канала: 70 dp, уменьшенные название/программа/время, логотип 31 dp, минимальные промежутки. При 720p и нижнем описании должно помещаться больше каналов.
4. Выделенная строка канала, текущая программа и выбранная дата прокручиваются к общему вертикальному центру. Для первого/последнего элемента добавлены верхний и нижний отступы списков.
5. Выбор даты сохраняется при смене канала. Если программа на этот день недоступна для данного канала, показывается корректное состояние пустого дня, а не ложная программа другого дня.
6. Видимые строки нового широкого гида теперь передают идентификаторы в `VisibleChannelsChanged`, чтобы существующий EPG-репозиторий подгружал `nowPlaying` для реальных видимых каналов.
7. Прежняя компоновка описания снизу/справа, изображения TMDB и резервное поле Kinopoisk.dev не удалены.

## Проверки

- Сопоставлены вызовы `WatchingLayout` → `AndroidWideGuide` → `ChannelsComponent.VisibleChannelsChanged`.
- Проверены баланс скобок Kotlin и отсутствие прежнего опасного приведения типов.
- Полная Android Gradle-сборка **не выполнялась**: Android SDK и установленного Gradle в этой среде нет. Запуск на физическом TCL также не проверен.
- Эталон — оригинальный APK TVNext 0.5.21; восстановленный проект не заявлен идентичным ему пиксель-в-пиксель.

## Единственная проверка у агента

`gradle :apps:android:assembleRelease --stacktrace --console=plain`

После установки проверить: открытие/закрытие настроек шестерёнкой; список каналов в середине длинного списка; строку текущей программы и время/прогресс; совпадение по высоте выбранного канала/передачи/даты; переход по датам с пульта; возврат в просмотр.
