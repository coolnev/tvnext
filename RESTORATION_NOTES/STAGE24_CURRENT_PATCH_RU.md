# TVNext — рабочий пакет изменений после TVnextR-source(2)

Исходная база: пользовательский архив `TVnextR-source(2).zip`, который собирался у агента.

Изменения:
- Back из полноэкранного просмотра открывает оконный режим; Back из оконного — главное меню (исправлены конфликтующие пути).
- При постере текст располагается ближе к реальной ширине изображения.
- Панель категорий появляется слева, сохраняя справа список каналов, передач и дат.
- Загрузка EPG защищена от повторных одновременных запросов; автоматический запрос имеет защитный интервал; работа по импорту направлена на фоновый поток; после ошибки предусмотрена ограниченная повторная попытка.
- Для Kinopoisk.dev добавлен запрос подробной карточки при отсутствии описания в результатах поиска; TMDB запрашивает английский текст, если русский пуст. Отдельные поля (текст/кадр/постер) дополняются без потери уже найденной картинки.
- В верхнем правом углу нижней панели — тематические квадратные индикаторы фактического разрешения и аудиоканалов. Примеры: 720p, 1080p, 4K; Mono, Stereo, 5.1, 7.1. Данные только из выбранных дорожек Media3; неподтверждённые скрыты. Показ включён для оконного просмотра, полноэкранной панели каналов и медиатеки.

Проверка: 8 самостоятельных тестов преобразования технических метаданных пройдены. Целостность исходного ZIP и неизменённых файлов проверена; сборка Android/Compose и запуск на TCL не производились. Наличие актуальной телепрограммы и доступность TMDB/Kinopoisk.dev необходимо проверять на устройстве.

Проверить агентом: `:apps:android:assembleRelease`. Затем проверить вход/выход Back, категории, EPG во время воспроизведения, тексты описаний, индикаторы 1080p/4K и звуковых каналов при смене потока и при пустых данных.
