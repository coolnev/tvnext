# TVNext: этап 11 — единое меню и нижняя панель (Android)

Основа: `TVNext_0521_STAGE10_TOUCH_VERIFIED_SOURCE.zip`. **Эталоном для проверки поведения остаётся оригинальный APK TVNext 0.5.21**. Этот проект — восстановительная сборка, не официальный релиз 0.5.21. Код из 0.5.22–0.5.27 не переносился.

## Изменения

1. **Одно главное меню на главной слева.** В AppSidebar добавлены Редактор каналов, Мои записи, Профили, Запись и расписание, Резервная копия и Настройки. Удалён дополнительный `RecoveryMainMenu` / `AlertDialog`. MENU пульта возвращает на главную. Левое меню прокручивается при малой высоте. Доступ к отдельным функциональным диалогам из этого меню сохранён.
2. **Общая нижняя Android-панель.** В `AndroidPlaybackControls` есть кнопка `Формат: <текущий режим>` слева; ↶ (предыдущий канал и обратно); одноцветные кнопки перемотки; пауза для поддерживаемого воспроизведения; LIVE/Описание/Закрыть; справа — `● Записать эфир` для прямого эфира. Команды передаются Android Activity через `PlaybackUiRequests`. Реальная запись запускается имеющейся `RecordingService` (HLS/TS), не новым псевдосервисом.
3. **Оконный режим каналов.** Общая панель показана также для Live-каналов без архива, а не только для архивных. Кнопка «Описание» реально открывает текст программы. Список каналов, категории и программа занимают фиксированный контейнер шириной 400 dp; при переходе канал → передачи место видео не сжимается и не расширяется.
4. **Полноэкранный режим и медиатека.** `AndroidProgrammeOverlay` и `AndroidMediaScreen` используют эту же панель. В полноэкранном режиме кнопки появляются в нижней информационной/транспортной области при открытом оверлее (не постоянно поверх картинки).
5. **Предыдущий канал.** Текущий/предыдущий ID сохраняется в памяти сессии, повторные нажатия переключают A → B → A → B. При смене профиля история очищается.
6. **Без жёлтых стрелок.** Seek-кнопки рисуются одноцветными треугольниками на `Canvas`, а не цветными системными emoji.
7. **Часы без фона.** Отдельный переключатель в «Настройки → Интерфейс». Значение сохраняется в существующем SettingsRepository. При включении у цифр нет подложки, есть белый цвет и тень. Положение часов настраивается отдельно, настройка сама по себе часы не включает.
8. **Компактные настройки.** Уменьшены отступы в уже существующих вкладках Android; скрыты ненужные Android пункты разрешения окна Windows. Desktop-код не изменён.
9. **Компактнее список каналов.** Высота строки 82 → 70 dp, одновременно вертикальные отступы содержимого сокращены до 3 dp, чтобы три строки информации не обрезались. Реальную читаемость необходимо проверить на TV с увеличенным системным шрифтом.
10. **Жест категорий.** В оконном режиме и при открытом полноэкранном списке свайп вправо из первых 42 dp, пройдя 90 dp, открывает категории. Вертикальный скролл и D-pad обрабатываются независимо. Изменения реализованы только для Android.

## Что проверено локально

- `PreviousChannelHistory` компилируется отдельным Kotlin/JVM-компилятором и проходит 7 проверок.
- 20 проверок соединений интерфейса и исходников (`tools/check_stage11_ui.py`) пройдены.
- Синтаксических диагностик в доступной проверке Kotlin K2 не найдено, но Android/Compose зависимости в локальном окружении отсутствуют; это **не** проверка компиляции проекта.
- Изменённые и добавленные файлы находятся в модулях Android и common; код `apps/desktop` не изменён.

## Что НЕ проверено

- `:apps:android:assembleRelease` через полноценный Android SDK/Gradle 9.4.1 — недоступно в этой среде.
- Поведение UI при разных разрешениях, фокус D-pad, свайп, сенсорный экран и реальная запись на телевизоре.
- Пиксельное соответствие оригинальному APK 0.5.21. Оно **не гарантируется**.

## Проверка у агента (одним запуском)

1. Открыть исходники в отдельной папке; не накладывать поверх оригинальной 0.5.21.
2. Запустить `gradle :apps:android:assembleRelease --stacktrace --console=plain`. Не менять Gradle/AGP/Kotlin и `externalNativeBuild`, если она присутствует.
3. На устройстве: Главная → слева редактор и записи; MENU; обе панели проигрывания, форма видео, ↶, архивная перемотка, запись/остановка; настройки часов; плотность списка; категории свайпом и пультом; при переходе к программе проверить неизменные размеры видео.
4. Проверить, что APK имеет `applicationId = com.tvnext.app.recovery`, не устанавливается поверх эталонной версии.
5. Если возникнут ошибки компиляции, исправлять только конкретные ошибки, не подменять экраны или механизмы заглушками. Не переписывать Windows.
