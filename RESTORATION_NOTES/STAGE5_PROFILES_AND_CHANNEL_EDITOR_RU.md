# TVNext — этап восстановления 5 (Android)

База: **TVNext_0521_RESTORED_STAGE4_FROM_AGENT.zip** — подтверждённая пользователем сборка этапа 4.
Эталон сравнения: **оригинальный Android APK 0.5.21, versionCode 35** (28 октября 2026).
Выпуски 0.5.22–0.5.27 не применялись. Windows не изменялась.

## Реализовано

1. **Профильное избранное LIVE и VOD.** Android-репозитории показывают избранное текущего профиля. Исторические флаги базы первоначально копируются в основной профиль. Медиатека, Поиск, Главная и Каналы получают одни и те же персональные данные.
2. **Профильная история** (до 20 элементов) и **последний канал**. Старые записи истории при первом чтении переносятся в «Основной». Гостевой профиль изначально пустой. При переключении профиля воспроизведение останавливается и персональный кэш сессии очищается.
3. **Тема и цвет акцента** каждого Android-профиля отдельно. Общие параметры потока, EPG и плейлистов остаются общими. Персональные данные хранятся в приватном Android SharedPreferences, независимом от таблиц M3U.
4. **Редактор каналов** по кнопке «Редактор каналов» в панели MENU: поиск, переименование, переназначение категории, скрытие/восстановление, избранное, перемещение выше/ниже, скрытие дубликатов с идентичным URL, сброс списка провайдера с сохранением избранного.
5. **Независимость EPG от переименований/скрытия.** Сопоставление программы передач работает с исходными каналами и tvg-id; редактор изменяет только отображение, не переписывая M3U или SQL-строки.
6. **Обновление сохранённых вкладок** «Каналы» и «Главная» после закрытия редактора, без скачивания плейлистов и без перезапуска воспроизведения.
7. **Фокус пульта** восстанавливается при возврате из редактора.

## Реальные проверки, выполненные в этой среде

- Kotlin/JVM-компиляция чистой функции проекции и её выполнение: пройдено (избранное, порядок, скрытие, дубликаты, rename/category, сохранение tvg-id и адресов источника).
- Kotlin/JVM-компиляция Android-репозиториев с тестовыми заглушками платформенных интерфейсов, функциональный тест: пройден (миграция основного профиля, изоляция истории и избранного, профильная тема и последний канал).
- Kotlin/JVM-компиляция класса персонального хранилища с интерфейсными заглушками Android/JSON: пройдена. Это проверяет типы и синтаксис, НЕ физическое хранение на Android.
- Сравнение с этапом 4: изменены только восемь Android/Android-связанных исходников плюс этот документ; `apps/desktop` и CMake/NDK не менялись.
- **Android Gradle-сборка не выполнена.** Wrapper Gradle 9.4.1 не может скачать дистрибутив (`UnknownHostException: services.gradle.org`). Подтверждения запуска на ТВ нет.

## Обязательно проверить у агента с Android SDK

```
./gradlew :apps:android:assembleRelease --stacktrace --console=plain
```

Сначала сделать резервную копию работающей базы этапа 4. Не делать `git clean/reset` и не разворачивать архив поверх эталонной 0.5.21. Проверить на Android TV:

- Запуск после обновления восстановительного приложения (`com.tvnext.app.recovery`), без потери старых данных.
- В основном профиле существующие LIVE/VOD избранное и история не пропали.
- Создать второй профиль, добавить избранное и посмотреть VOD; вернуться в основной — избранное и история не смешались.
- Менять темы по отдельности, переключать профили, закрывать/открывать приложение.
- Переименовать/скрыть канал, обновить плейлист, убедиться, что редактор сохранил изменения и EPG продолжает находить передачи.
- Проверить «Вернуть список провайдера»: имена, категории, порядок восстановились; избранное сохранилось.
- Проверить D-pad / Back / OK, возврат фокуса после редактора, отображение скрытых каналов в редакторе.
- Не проверять реальными ключами/потоками из логов и не публиковать исходники в открытом репозитории.
