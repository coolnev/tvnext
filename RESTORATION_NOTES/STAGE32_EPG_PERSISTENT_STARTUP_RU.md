# TVNext — постоянный EPG и быстрый старт (этап 32)

Исходная база: оригинальный архив пользователя `TVnextR-source(3).zip` от 4 ноября 2026 года.

1. Android: полный EPG теперь хранится в `noBackupFilesDir/epg_cache`, а не в `cacheDir`, который ОС может очистить. Старый каталог переносится без потери импортированных данных (при невозможности переноса временно используется прежний каталог).
2. После успешного импорта записываются два файла: `epg_programs.dat` (полная история) и `epg_current.dat` (текущие и ближайшие 16 часов + 2 часа назад). Оба записываются атомарно, не заменяя полноценный архив быстрым индексом.
3. На запуске программа сначала читает небольшой файл `epg_current.dat` без сети и сразу передаёт данные списку каналов. Полная история загружается по запросу телегида/архива.
4. Фоновая проверка EPG через 4 секунды при свежем кэше не читает весь огромный архив и не скачивает XMLTV; TTL остаётся штатным: 12 часов. При истечении TTL сохранённая программа не исчезает во время нового импорта.
5. Проверка времени кэша читает одну строку заголовка, а не весь файл. Неполная/прерванная загрузка кэша больше не считается успешной.
6. При пользовательском полном сбросе приложения удаляется также новый постоянный EPG-каталог.
7. Старые установки с одним файлом полного EPG получают быстрый индекс при первом успешном локальном чтении, без принудительной повторной загрузки XMLTV.

Ограничения: сохранённая программа не заменяет данные, которых изначально не было у поставщика. Обновление по истечении TTL, ручное обновление и смена источника остаются предусмотренными сценариями.

Сборка не выполнена: в среде нет дистрибутива Gradle 9.4.1, а его загрузка недоступна. Добавлены desktop unit-тесты на повторный запуск без сети и корректную обработку прерванного чтения; запуск тестов требует Gradle.
