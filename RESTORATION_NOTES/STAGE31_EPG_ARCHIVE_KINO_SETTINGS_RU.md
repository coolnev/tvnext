## Архив и EPG

- Реальный XMLTV основного провайдера — приоритетный источник прошлых передач. История, уже загруженная ранее, сохраняется при обновлении скользящего EPG; окно хранения старых записей больше не зависит от выбранной глубины архива (30 дней по умолчанию, не больше 60 дней для удерживаемой истории). Программа, которой вообще нет ни в каком скачанном XMLTV, не создаётся искусственно.
- В Настройках → Воспроизведение пункт «Глубина архива» показывает выбранное значение: автоматически, 1, 2, 3, 7, 14, 30 дней. Выбор сохраняется в SettingsRepository. В списке каналов и телегиде он ограничивает **отображаемый** диапазон, не удаляя кэш EPG. Автоматически = всё реально загруженное EPG; доступность воспроизведения архивных передач отдельно ограничена возможностями провайдера.
- Изменение глубины вызывает событие обновления дат телегида, а в каналах сбрасывает временный кэш списка старых передач без повторного скачивания XMLTV.
- Сопоставление XMLTV дополнено одновременными tvg-id, tvg-name и именем канала, а также просмотром ВСЕХ display-name в XMLTV. У разных провайдеров названия могут вообще не совпадать — тогда понадобится вручную проверить EPG-идентификаторы или сам источник.
- 10-минутный таймер телегида обновляет только отображение передач, **не запускает запрос скачивания EPG**. Плановая загрузка основного XMLTV остаётся по TTL (12 ч); при ошибках сохраняются ограниченные повторы.

## Кинопоиск / ПоискКино API

- Добавлено ограничение числа одновременных запросов и тайм-ауты; временные ошибки HTTP 5xx повторяются один раз, HTTP 429 и 401/403 переводят клиент в ограниченную паузу, не обрушивая запросы на API.
- Временный сетевой сбой не записывается как устойчивое отсутствие описания; отрицательный кэш уменьшен до 20 с, неполного описания — 30 с.
- При сохранении/замене API-ключа сбрасываются локальная пауза и кэш карточек. Не нужно открывать «Проверить соединение» для старта работы.
- **Внешние ограничения API:** HTTP 401 означает неверный токен, HTTP 403 может означать исчерпание суточной квоты. Изменения клиента не обходят эти лимиты.

## Настройки

- Пункт «Тема» теперь выбирает четыре набора акцентных цветов (классическая, морская, тёплая, фиолетовая); собственный «Цветовой режим» (тёмный/светлый/система) сохранён отдельно.
- «Прозрачность панелей» — 0…80% и реальное изменение цветов поверхностей в MaterialTheme, значение сохраняется.
- «Стартовый экран» — Главная, Каналы, Телепрограмма, Медиатека; используется при запуске Android приложения (по умолчанию Каналы, как и на этапе 30).
- Левая колонка настроек меняет содержимое справа при получении фокуса от пульта, без ОК; правая часть прокручивается к началу.
- Исправлено немедленное обновление Theme/Accent в персональных профилях после сохранения.
- «Язык интерфейса» остался информационным: в текущей восстановленной ветке реализован только русский язык. Не создавали фиктивный пункт English без перевода интерфейса.
