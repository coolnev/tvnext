# TVNext — этап 18: исправления интерфейса и метаданных передач

Основа: полный архив Stage 17 (`TVNext_0521_STAGE17_GUIDE_FOCUS_SOURCE.zip`).

## Интерфейс Android TV
- Убраны рамки вокруг целых колонок (каналы / телепрограмма / даты). Выбранная строка выделяется только в активном столбце, поведение стрелок и OK от Stage 17 сохранено.
- Селектор профиля подстраивается под длину имени: ограничена только максимальная ширина; стрелка расположена сразу после имени.
- `Редактор каналов` и `Мои записи` используют тот же компонент навигации, что `Главная`, `Каналы`, и др., с общими отступами, шрифтом и визуальными состояниями.
- Настройки остаются за шестерёнкой, а не в левом меню.

## Метаданные и сеть
- В строке поиска отброшены обычные XMLTV-префиксы `х/ф`, `т/с`, `м/ф`, `д/ф`; сопоставление остаётся строгим, чтобы не подтягивать чужую картину.
- Пустые результаты вспомогательного кэша программы больше не удерживаются целый час: не более 3 минут.
- При изменении TMDB API-ключа / переключении TMDB в настройках оперативно сбрасывается кэш подсказок EPG (в памяти).
- Проверка соединения TMDB на Android выполняет один запрос с ограничением времени до 7 сек вместо повторных долгих попыток. В настройках видно, отклонён ли ключ или отсутствует ответ от сервера.
- Неудача загрузки кадра теперь не блокирует попытку загрузить постер. При отсутствии обоих изображений панель по-прежнему использует всю ширину под текст.
- Kinopoisk.dev работает только с ключом, который пользователь ввёл вручную. Ключи из настроек никуда не копируются и в диагностические сообщения не выводятся.

## Что проверено
- Самостоятельный `kotlinc`-smoke-test нормализации названий (5 случаев) — успешно.
- Исходники и ZIP — проверки целостности. Конфигурация Gradle и `externalNativeBuild` не менялись.
- Android Gradle-сборка и фактическая сеть телевизора здесь не проверены. Доступность TMDB на конкретном телевизоре / у оператора нельзя подтвердить по исходникам. Для этого использовать кнопку «Проверить соединение» в настройках.

## Проверить после сборки
1. Открыть гид: никаких рамок вокруг **всех** колонок, фокус на выбранной строке.
2. Пультом перейти между каналами/передачами/датами; переключить канал одним OK, проверить, что вылетов нет.
3. Главная: профиль справа компактный, стрелка рядом с именем; Editor/Recordings оформлены так же, как другие пункты.
4. Настройки → Медиатека: проверить соединение TMDB, различить сообщение про ключ и сеть.
5. Смена TMDB-ключа или переключение опции → открыть гид, убедиться, что описание обновляется после перехода к передаче.
6. Отключить TMDB, проверить fallback Kinopoisk.dev с **личным** ключом на известных фильмах и сериалах.

Если TMDB всё ещё сообщает «нет ответа», необходима диагностика сети/DNS/TLS устройства; никакие локальные изменения не гарантируют работу внешнего API при недоступности его адреса.
