# TVNext — этап 12: настройки по фото эталона 0.5.21

## Основа
Полный проект этапа 11. Windows-реализация настроек, версии сборки, native-конфигурация и плеер не менялись. Восстановительный Android `com.tvnext.app.recovery` не заменяет оригинал.

## Изменения Android
- Убран повторный пункт «Настройки» из левого меню. Вход только через шестерёнку в шапке главной.
- Слева от шестерёнки добавлен выпадающий список профилей с названием активного профиля, отметкой активного профиля и переключением на другой. При переключении останавливается плеер, при необходимости — ручная запись; очищается история кнопки предыдущего канала; Activity пересоздаётся для обновления персональных репозиториев.
- В настройках Android вместо прежней длинной страницы подключена отдельная компактная двухколоночная раскладка: 9 разделов слева и пункты справа, как на снимках пользователя.
- Разделы «Оформление» и «Запись» имеют плотные строки; высота адаптируется для небольших экранов. Для совсем маленькой высоты сохраняется резервная прокрутка, чтобы строки не обрезались.
- Значения действующих настроек выводятся из SettingsState или хранилища записей. Тема, акцент, часы, время информации EPG, канал/декодер/буфер, запасы записи и лимит хранения вызывают реальные действия сохранения.
- Экран «Общие → Профили» открывает существующее управление профилями, «Плейлисты и EPG → Редактор каналов» — редактор, «Обслуживание» — резервную копию. Настройки папки записи открывают существующий выбор доступных накопителей.
- Раздел «О приложении» выводит фактическую версию установленного восстановительного APK из PackageManager, а не фиктивное «0.5.21».

## Подтверждённые ограничения
- Исходная сентябрьская база не содержит работающего механизма родительского PIN/ограничения каналов — эти пункты обозначены «Недоступно». Скрывать это нельзя.
- Язык, классическая тема, положение описания и прозрачность панелей в сохранённом восстановительном проекте не имеют реализованных хранилищ/действий — соответствующие значения показаны как недоступные для изменения, а не фиктивные переключатели.
- Нажатие «Выбрать папку»/«Выбрать без проводника» сейчас открывает существующее окно настроек записи; прямое точное разделение двух сценариев 0.5.21 требует отдельной работы.
- Сходство с фотографиями — по структуре и плотности, но пиксельное совпадение не проверено.
- Android APK не собирался и не тестировался на физическом TCL в этой среде: Gradle/Android SDK здесь отсутствуют.

## Изменённые файлы
1. `core/app/src/commonMain/kotlin/com/tvnext/app/core/app/AppShell.kt` — шапка, профиль, главное меню и Android slot настроек.
2. `apps/android/src/main/kotlin/com/tvnext/app/MainActivity.kt` — реальные профили/события/маршрутизация.
3. `apps/android/src/main/kotlin/com/tvnext/app/AndroidReferenceSettingsScreen.kt` — новый Android экран настроек.
