## Реализовано на этом этапе

1. **Главное меню Android TV:** по пульту MENU и кнопке «Главное меню» на главной. Внутри отдельные пункты «Редактор каналов», «Мои записи», «Профили», «Запись и расписание», «Резервная копия профилей». Убрана отдельная кнопка «Мои записи» из нижней части главной. Редактор каналов больше не скрыт внутри панели записей. Оба раздела находятся в главном меню.
2. **Индивидуальные настройки канала и профиля:** режим масштаба FIT/FILL/ZOOM, предпочтительные языки аудио/субтитров, выключение субтитров. Media3 применяет эти параметры при открытии канала; PlayerSurface применяет масштаб без изменения данных плейлиста.
3. **VOD resume по профилям:** отдельные позиции в приватном хранилище для каждого профиля; исходная общая позиция основного профиля читается при первом обращении, Windows оставлен на прежнем SQL-пути. Смена профиля очищает временный кэш позиции, как было в этапе 5.
4. **Архив resume по профилям:** запоминаются позиции для сочетания ID канала и времени начала передачи, без сохранения временного URL. Хранятся до 20 записей, обновление не чаще 1 раза в 10 секунд. При повторном открытии того же архивного элемента делается seek (если это не переход самого timeshift).
5. **Резервные копии профилей:** экспорт/импорт через системный выбор JSON-файла с предварительной полной проверкой и подтверждением. Включает имя, профильное избранное и историю, оформление, редактор каналов, индивидуальные параметры, VOD/архивные позиции. Исключает URL потоков, ключи API, PIN и видеофайлы. Нельзя импортировать копию, которая оставит текущие записи/расписание без профиля-владельца. Не заменяет полный экспорт пользовательской БД 0.5.21.
6. **Запись из EPG:** в карточке будущей передачи Android TV-гид предлагает «Запланировать запись». В диалоге настраивается запас времени до/после (по умолчанию 2/5 мин, диапазон 0..60). Проверяются прошедшее время, максимальная общая длительность шесть часов и пересечение с существующими заданиями. Запись принадлежит активному профилю. Прежние напоминания не затронуты.
7. **Параметры записи:** в разделе «Запись и расписание» изменяются общие значения запаса до/после. Доступны существующие выбор накопителя, лимиты, уведомления, ручной старт/стоп и просмотр расписания. «Мои записи» теперь выделены в собственный раздел.

## Ограничения и что осталось от оригинала 0.5.21

**СБОРКА ЭТОГО ЭТАПА НЕ ПОДТВЕРЖДЕНА** — в этой среде нет Android SDK, а Gradle Wrapper не может скачать дистрибутив. У агента пользователя есть среда, в которой предыдущая версия собиралась.

- Принудительное видео-декодирование AUTO/HARDWARE/SOFTWARE и цепочка аппаратный → системный software → FFmpeg **не восстановлены**, параметры кодеков не подменялись обещаниями. Android использует текущий Media3/ExoPlayer.
- Точный пиксельный интерфейс оригинальной 0.5.21, темы «Контур», раскладка плеера/гида и все особенности пульта **не восстановлены** полностью.
- Произвольные соотношения 16:9, 4:3, 2.35:1 и т.д. в новом редакторе не реализованы: есть три подтверждённые стратегии FIT/FILL/ZOOM Media3.
- Нет полноценной реализации проигрывания всех HLS с отдельным аудио, полной нативной цепочки FFmpeg, редактирования отдельных дорожек и точной логики записи 0.5.21.
- Наличие рабочего APK не означает пиксельного совпадения с эталоном.

## Проверка в Android Studio / у агента

```powershell
.\gradlew.bat :apps:android:assembleRelease --stacktrace --console=plain
```

После сборки проверьте на Android TV: меню пульта MENU, пункты «Редактор каналов» и «Мои записи», закрытие диалогов Back/OK, выбор/смену профиля, избранное, настройку аудио и масштаба канала, просмотр одного VOD отдельно в двух профилях, resume архива после перезапуска, резервный экспорт/импорт с подтверждением, запись будущей передачи из EPG и отказ при пересечениях. Проверьте, что установленный оригинальный APK 0.5.21 остался нетронутым.

**Не публиковать исходное дерево/JAR в открытый репозиторий:** исходная база может содержать приватные настройки провайдеров. Публикация APK отдельно разрешалась раньше, не исходников.
