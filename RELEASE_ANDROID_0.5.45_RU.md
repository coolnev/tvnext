# TVNextR 0.5.45 — Android

Пакет `com.tvnext.app.recovery`, versionCode 545, прежняя подпись. Установка поверх 0.5.44. APK `releases/android/TVNextR-0.5.45.apk`. SHA-256 `38435cce951295fc6913c2996240323f8c295b2f0b687acf3ced4c29575e0cc6`. Исходники `0066ad9d4279fa1397c34d7c6f2bfbea2c8a3405`.

В «Оформление» добавлен выключенный по умолчанию переключатель «Анимация». При включении одно и то же видео за 420 мс меняет размер и положение между полным экраном, оконным просмотром, маленьким экраном ТВ-гида справа вверху и главным экраном. Поток не запускается заново при смене окна. На главной рядом с карточкой текущего канала/фильма показано настоящее видео; OK возвращает к просмотру. Прокрутка главной обрезает окно, сохраняя геометрию самого видео.

При включённой анимации Android использует TextureView, при выключенной — прежний SurfaceView. Внутри приложения сохраняются общий плеер и один нативный видеовид; размеры меняются отдельно от воспроизведения. Включение/выключение самого эффекта меняет вид поверхности один раз. Прямоугольный баннер Android TV и значки сохранены.

В «Общие» добавлен выключенный по умолчанию переключатель «Запускать TVNext при включении», с пояснением о выходе из спящего режима. На Android 10+ при первом включении открывается системное разрешение «Поверх других приложений». Без разрешения переключатель не включается. Реальный цикл выключения/включения экрана возвращает существующее приложение или запускает его с обычными сохранёнными стартовыми настройками. Сама загрузка Android не открывает интерфейс: она только восстанавливает наблюдение за следующим сном. Наблюдатель работает как тихая foreground-служба, получает системные события, не опрашивает экран и не удерживает телевизор включённым. На заблокированном устройстве ожидает разблокировки. Отключение переключателя останавливает службу.

Прошли 182 проверки: 72 Android native на API 28/35, 99 каналов/плеера/интерфейса, 6 главной и 5 ТВ-гида. Проверены промежуточное положение анимации, переходы, отсутствие нового play/пересоздания поверхности, клип при прокрутке, LIVE/VOD-превью, события сна, повторные события, блокировка, sticky-restart, загрузка Android, разрешение и ошибка foreground-службы. Выполнены encoding/release/lint, подпись, ZIP/zipalign, сохранение встроенного ключа; все PNG совпадают с 0.5.44.

Сам release APK запущен в программном эмуляторе Android 9 с локальным H.264/AAC; нативный плеер и TextureView сохраняются при изменении размеров. Программный декодер выбран только в тестовых данных эмулятора, у которого нет аппаратного видеодекодера. Проверены переходы полный экран → главная → ТВ-гид → полный экран с одной TextureView и продолжающейся позицией; после SCREEN_OFF/ON приложение вернулось с лаунчера Android. В нативном прогоне ТВ-гида проверялось окно видео; заполненная сетка и навигация проверены отдельно пятью UI-тестами. Скриншоты и отчёты приложены. Физический Google TV не использовался: плавность и ограничения его прошивки на запуск после сна требуют проверки на телевизоре.
