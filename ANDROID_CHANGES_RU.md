# Android: навигация, архив и ТВ-гид

Изменения сделаны для Android. Исходные файлы desktop/Windows побайтно сохранены.
В общих Kotlin-файлах платформенные изменения ограничены Android-ветками; для ТВ-гида добавлен отдельный Android-экран. ZIP содержит полный исходный проект, необходимый для сборки.

## Каналы

- У каждого канала постоянный FocusRequester. Видимый канал получает фокус сразу, без предварительного центрирования списка и ожидания кадра. При переходе к невидимой строке старая рамка убирается перед прокруткой.
- На Android толщина рамки и состояние фокуса обновляются без анимации на 120 мс.
- Обычный список и полноэкранная панель сохраняют ID подсвеченного канала по категории, включая список без поискового запроса.
- Повторный выбор категории больше не сбрасывает её на «Все». При возврате категория сначала прокручивается в видимую область, затем получает фокус.
- «Все» на Android отображает плоский список каналов.
- Оконная EPG загружается для канала под курсором. Предыдущий запрос отменяется; ответ для старого канала не перезаписывает новый выбор. Воспроизведение от перемещения курсора не переключается.

## Архив

- Часы зависят от объявленной провайдером поддержки архива, а не от наличия текущей передачи в EPG. Флаги 0, false, none, off, disabled не считаются поддержкой.
- OK на часах не перехватывается обработчиком выбора/избранного строки канала.
- Оконная панель передаёт в воспроизведение ID канала, чей архив открыт.
- Реальная доступность архива по-прежнему проверяется существующим ArchiveRepository при запуске: одного флага в плейлисте недостаточно для гарантии, что сервер отдаст запись.

## Новый Android ТВ-гид

- Фиксированная колонка каналов слева, единая горизонтальная шкала с делениями по 30 минут.
- Передачи представлены блоками пропорционально длительности; текущая передача выделена, текущее время показано красной линией.
- ↑/↓ меняют канал с сохранением выбранного времени; ←/→ переходят по передачам. OK открывает информацию и действия. На верхней строке ↑ переводит к кнопкам управления. Back выходит из гида.
- Кнопки категорий, предыдущего/следующего дня, «Сейчас» и обновления EPG.
- В карточке доступны прямой эфир, просмотр с начала для каналов с архивом, напоминание для будущей передачи.
- Загружаются видимые строки с корректными ID каналов. В старой сетке viewport передавал playlistId|channelId вместо channelId.
- Версия EPG отслеживается отдельно для каждой загруженной строки; запоздавшие ответы предыдущей версии отбрасываются.
- Граница дня на Android рассчитывается по локальному календарю с учётом смены часового смещения.

## Проверка

Выполнены просмотр изменений, проверка структуры скобок изменённых Kotlin-файлов и побайтная сверка 78 исходных desktop-файлов.
Добавлены регрессионные тесты AndroidArchiveIndicatorTest для отсутствующего архива, выключенных флагов и поддержки архива без текущей EPG.

Сборка и запуск тестов НЕ подтверждены. Команда `bash gradlew :apps:android:assembleDebug --no-daemon` остановилась до компиляции: среда не имеет доступа к services.gradle.org для скачивания Gradle 9.4.1 (Network is unreachable). APK не включён. На Android TV/эмуляторе изменения в этой среде не запускались.

Для сборки на компьютере с JDK 17+, Android SDK и доступом к зависимостям:

    gradlew.bat :apps:android:assembleDebug

Перед установкой рабочей версии проверить:

1. Быструю прокрутку вверх/вниз, начало/конец списка в обоих режимах.
2. Категория → канал → категория; «Все», «Избранное» и категорию далеко внизу.
3. Возврат из полного экрана и из архива к прежнему каналу.
4. EPG при движении курсора без нажатия OK; играющий канал остаётся прежним.
5. Часы у архивного канала, отсутствие часов у неархивного, правильный канал в открытом архиве.
6. ТВ-гид на каналах ниже первых восьми, переход по дням, обновление EPG, длинные передачи и пустую телепрограмму.
